# 02 架构设计

## 1. 架构概述

CodeWidget（出勤码展示工具）采用以下核心架构原则：

**技术基础：** Python 3.12 + PySide6 桌面应用。

**三文件 JSON 配置：** 配置层分为三个独立文件。`school_config.json` 保存全校通用的时限信息与学期授课日历，可在教师之间共享；`teacher_config.json` 保存个人课程设置、调整规则与出勤码，每位教师独立维护；`settings.json` 保存应用全局设置（当前激活的教师配置文件路径及悬浮窗外观参数）。三者通过 `course_type` 与 `weekday` 关联，相互解耦。

**排课引擎与 GUI 完全解耦：** `src/engine/` 目录下的排课逻辑为纯 Python 函数，不依赖任何 GUI 组件。引擎接收数据模型对象、返回 `ScheduledClass` 列表，GUI 层仅负责调用引擎并展示结果。这一设计使得引擎可独立进行单元测试，且未来替换 GUI 框架时引擎代码无需改动。

**显示时机判断：** 应用每 30 秒检查一次当前时刻是否落在某门课的"显示窗口期"内（默认课前 10 分钟至课后 30 分钟，可通过 `Settings.pre_class_minutes` / `post_class_minutes` 配置）。命中则弹出置顶悬浮窗展示出勤码，超出窗口期后自动隐藏。

## 3. 数据模型

所有数据模型均使用 Python `dataclasses` 实现，通过 JSON 文件持久化。

### 3.1 SchoolConfig（`src/models/school_config.py`）

全校通用配置，对应 `school_config.json`。

#### Period — 单个时限的起止时间

```python
@dataclass
class Period:
    start: str  # "HH:MM" 格式，例如 "08:50"
    end: str    # "HH:MM" 格式，例如 "10:30"
```

#### CourseType — 课程类型定义

```python
@dataclass
class CourseType:
    name: str
    semester_id: str          # 关联的学期 ID，例如 "spring_2026"
    session_keys: list[str]   # 使用的回次键列表，例如 ["01", "02", ..., "14"]
                              # 或 ["01", ..., "07"]（Q 系课程）
    slots_per_week: int       # 每周授课次数：spring/autumn 为 1，Q 系为 2
```

#### SemesterDates — 单个学期的授课日历

```python
@dataclass
class SemesterDates:
    semester_id: str    # 例如 "spring_2026"
    semester_name: str  # 例如 "2026春セメスター"
    semester_start: str # "YYYY-MM-DD"
    semester_end: str   # "YYYY-MM-DD"
    # weekday_dates[曜日]["01".."14"] = "YYYY-MM-DD"
    # 曜日键："Monday" | "Tuesday" | "Wednesday" | "Thursday" | "Friday"
    weekday_dates: dict[str, dict[str, str]]
```

#### SchoolConfig — 顶层对象

```python
@dataclass
class SchoolConfig:
    periods: dict[str, Period]           # 键: "1"~"6"
    course_types: dict[str, CourseType]  # 键: "spring" | "autumn" | "Q1"~"Q4"
    semesters: list[SemesterDates]

    def get_semester(self, semester_id: str) -> SemesterDates | None: ...
```

### 3.2 TeacherConfig（`src/models/teacher_config.py`）

教师个人配置，对应 `<姓>_teacher_config.json`。

#### Slot — 单个授课槽位

```python
@dataclass
class Slot:
    weekday: str  # "Monday" | "Tuesday" | "Wednesday" | "Thursday" | "Friday"
    period: int   # 1~6
```

#### Course — 一门课程

```python
@dataclass
class Course:
    id: str            # 唯一 ID，例如 "course_001" 或院校课程编号
    name: str          # 课程名称，例如 "微積分A"
    course_type: str   # "spring" | "autumn" | "Q1" | "Q2" | "Q3" | "Q4" | "intensive"
    slots: list[Slot]  # spring/autumn 为 1 个 Slot；Q 系为 2 个 Slot
    course_code: str   # 院校课程代码（可为空字符串）
```

#### Override — 单条调整规则

```python
@dataclass
class Override:
    type: str               # "skip" | "makeup" | "reschedule"
    course_id: str          # 目标课程 ID

    # skip / makeup 共用字段
    date: str               # "YYYY-MM-DD"（跳过日期 或 补课日期）
    period: int | None      # 补课时限（makeup 时使用）

    # reschedule 专用字段
    original_date: str      # "YYYY-MM-DD" 原授课日
    original_period: int | None  # 原时限
    new_date: str           # "YYYY-MM-DD" 调整后授课日
    new_period: int | None  # 调整后时限
    new_start_time: str     # "HH:MM"（可选），覆盖时限标准开始时间
```

序列化时，`None` 与空字符串字段均被省略，JSON 文件中不出现对应键。

#### WindowPosition — 悬浮窗上次位置

```python
@dataclass
class WindowPosition:
    x: int = 100  # 屏幕 X 坐标（像素）
    y: int = 100  # 屏幕 Y 坐标（像素）
```

#### Settings — 显示时机参数

```python
@dataclass
class Settings:
    pre_class_minutes: int = 10   # 课前提前显示分钟数（默认 10）
    post_class_minutes: int = 30  # 课始后持续显示分钟数（默认 30）
```

#### Appearance — 外观参数

```python
@dataclass
class Appearance:
    code_font_family: str = "Arial"    # 出勤码字体
    code_font_size: int = 72           # 出勤码字号（pt）
    code_color: str = "#00ff7f"        # 出勤码文字颜色（十六进制）
    code_bg_color: str = "#ffffff"     # 出勤码背景颜色
    border_color: str = "#90CAF9"      # 窗口边框颜色
    course_font_family: str = ""       # 课程名字体（空字符串 = 系统默认）
    course_font_size: int = 11         # 课程名字号（pt）
    window_scale: int = 100            # 窗口缩放百分比（30~300）
```

> **设计背景（重写时注意）：** `Appearance` 类定义于 `teacher_config.py`，但 `TeacherConfig` 本身**不含此字段**——这是一处历史设计痕迹。外观参数最初属于教师个人配置（存于 `teacher_config.json`），后来被迁移到全局的 `settings.json` 统一管理，`Appearance` 类定义留在了 `teacher_config.py` 原位，`app_settings.py` 通过 `from models.teacher_config import Appearance` 引用它。`teacher_config.py` 的模块 docstring 中仍残留 `appearance{}` 字段描述，属于未清理的过时注释。**重写时建议将 `Appearance` 定义移至 `app_settings.py` 或独立的 `models/appearance.py`，使定义位置与实际使用位置一致。**

#### TeacherConfig — 顶层对象

```python
@dataclass
class TeacherConfig:
    teacher_name: str
    courses: list[Course]
    overrides: list[Override]
    window_position: WindowPosition     # 默认 WindowPosition(x=100, y=100)
    settings: Settings                  # 默认 Settings()
    academic_year: str                  # 例如 "2026"（可为空字符串）
    # 出勤码存储，键格式: "{course_id}_{session_key}"，例如 "RD010001E3_03"
    attendance_codes: dict[str, str]
```

### 3.3 AppSettings（`src/models/app_settings.py`）

全局应用设置，对应 `settings.json`。

```python
@dataclass
class AppSettings:
    active_config: str = ""         # 当前教师配置文件的绝对路径；
                                    # 空字符串 = 使用程序内置默认路径
    appearance: Appearance = ...    # 复用 teacher_config.py 中的 Appearance 数据类
```

`AppSettings.appearance` 是显示外观的"全局主配置"，加载时由 `settings.json` 中的 `appearance{}` 字段填充；若文件不存在则使用 `Appearance` 的默认值。

### 3.4 ScheduledClass（`src/engine/scheduler.py`）

排课引擎展开后的单次具体授课记录，是引擎输出与 GUI 输入之间的核心数据载体。

```python
@dataclass
class ScheduledClass:
    course_id: str      # 对应 Course.id
    course_name: str    # 对应 Course.name（冗余存储，便于显示层直接使用）
    date: date          # 具体授课日期（Python datetime.date 类型）
    weekday: str        # "Monday" | ... （与 Slot.weekday 一致）
    period: int         # 1~6
    session_key: str    # "01"~"14"（Override 重排后按实际发生顺序重新编号）
    slot_index: int     # 0 或 1（Q 系课程每周有 2 个 Slot，此字段区分第几个）
    custom_start: str   # "HH:MM"；非空时覆盖 period 标准开始时间（reschedule 用）
```

`ScheduledClass` 由 `resolve_course_schedule()` 生成，经 `override.py` 中的 `apply_overrides()` 修改后得到最终授课列表。

## 4. 课程类型体系

排课引擎支持的6种类型（spring/autumn/Q1–Q4）均恰好产生 **14 次**授课记录（春/秋学期：14 周 × 每周 1 次；Q 系：7 周 × 每周 2 次）。`intensive`（集中讲义）类型课程**不参与自动排课**，引擎直接返回空列表（`scheduler.py:35-36`）。

| 类型 | 学期 | 使用回次 | 每周次数 | 槽位数 |
|------|------|----------|----------|--------|
| `spring` | `spring_2026` | 01–14 | 1 | 1（单曜日 × 单时限） |
| `autumn` | `autumn_2026` | 01–14 | 1 | 1（单曜日 × 单时限） |
| `Q1` | `spring_2026` | 01–07 | 2 | 2（两曜日 × 各 1 时限） |
| `Q2` | `spring_2026` | 08–14 | 2 | 2（两曜日 × 各 1 时限） |
| `Q3` | `autumn_2026` | 01–07 | 2 | 2（两曜日 × 各 1 时限） |
| `Q4` | `autumn_2026` | 08–14 | 2 | 2（两曜日 × 各 1 时限） |

> **注意：** "使用回次"一列对应 `CourseType.session_keys`——即在 `weekday_dates` 中查找授课日期所用的索引键范围。对于 spring/autumn，该范围（"01"–"14"）与最终 `ScheduledClass.session_key` 完全一致；对于 Q 系，`session_keys` 仅是日期查找键（Q1/Q3 用 "01"–"07"，Q2/Q4 用 "08"–"14"），而每门 Q 系课程最终生成的 14 条记录的 `session_key` 均从 "01" 重新递增至 "14"（算法见下方编号规则）。

### Q 系课程的 session_key 编号规则

Q 系课程每周有 2 个 Slot（例如：周三第 2 限 + 周五第 3 限）。引擎将两个 Slot 视为同一"周"的两次授课，session_key 按**跨两个 Slot 连续递增**的方式分配：

```
第 1 周：水曜 Slot → session_key "01"，金曜 Slot → session_key "02"
第 2 周：水曜 Slot → session_key "03"，金曜 Slot → session_key "04"
……
第 7 周：水曜 Slot → session_key "13"，金曜 Slot → session_key "14"
```

这使得 Q 系课程的 session_key 在整个课程内全局唯一且连续，便于与出勤码键（`{course_id}_{session_key}`）一一对应。

### 授课日解析路径

```
Course.course_type
  → SchoolConfig.course_types[course_type]
      .semester_id  → SchoolConfig.get_semester(semester_id)
                          .weekday_dates[Slot.weekday][session_key]
                          → 具体授课日期（"YYYY-MM-DD"）
      .session_keys → 决定哪些回次键参与展开
```

## 5. 技术选型理由

### GUI 框架：PySide6（LGPL v3）

| 框架 | 免费版授权 | 闭源商业/内部分发 |
|------|-----------|-----------------|
| PyQt6 | GPL v3 | 不允许（须购买 Riverbank 商业许可） |
| **PySide6** | **LGPL v3** | **允许**（内部使用不触发分发条款） |

选择 PySide6 的具体理由：

1. **官方维护** — 由 Qt Company 直接维护，是 Qt for Python 的官方 Python 绑定，长期支持有保障
2. **合规性** — 本项目为学校内部部署工具，不对外销售，内部使用场景下 LGPL v3 完全合规，无需付费
3. **工具链完整** — 附带 `pyside6-deploy`、`pyside6-uic`、`pyside6-rcc` 等官方工具
4. **文档质量** — 与 Qt 官方文档深度集成，API 参考更完整
5. **API 兼容性** — 与 PyQt6 约 90% 兼容，未来迁移成本低

> **注意：** 若将来需要向校外分发打包版本（`.exe` / `.app`），须确保 Qt 动态库以独立文件形式存在（不完全合并进单一可执行文件），以满足 LGPL 的"可替换库"要求；或届时购买 Qt 商业许可证。

### JSON 配置文件

- 纯文本格式，可移植，无需数据库
- 支持手动编辑，便于教师自行调整
- 双文件分离（全校 / 个人）使共享与个性化互不干扰

### PyInstaller 打包

打包为独立可执行文件（Windows `.exe` / macOS `.app`），用户无需安装 Python 或任何依赖，降低部署门槛。

### 排课引擎纯 Python、与 GUI 解耦

`src/engine/` 中的函数不 import 任何 GUI 模块，可直接通过 `pytest` 进行单元测试。GUI 层仅调用引擎函数并展示其返回值，引擎逻辑变更不影响 GUI，GUI 重构也不影响引擎。

## 6. 配置文件说明

### `config/school_config.json` — 全校通用配置

由管理员或项目维护者维护，教师之间共享同一份文件。包含：

- `periods` — 第 1～6 限的标准开始/结束时间
- `course_types` — 6 种课程类型（`spring`、`autumn`、`Q1`～`Q4`）的学期关联与回次范围
- `semesters` — 春学期（`spring_2026`）与秋学期（`autumn_2026`）的完整授课日历，按曜日和回次键（`"01"`～`"14"`）精确记录每一次授课的实际日期（已扣除法定假日、学校活动停课日等）

### `config/<姓>_teacher_config.json` — 教师个人配置

每位教师独立维护自己的配置文件。包含：

- `teacher_name`、`academic_year` — 基本信息
- `courses` — 课程列表（`id`、`name`、`course_type`、`slots`、`course_code`）
- `overrides` — 停课/补课/调课规则列表
- `attendance_codes` — 已录入的出勤码，键格式为 `"{course_id}_{session_key}"`
- `window_position` — 悬浮窗上次关闭时的屏幕位置
- `settings` — 显示时机参数（`pre_class_minutes`、`post_class_minutes`）

### `config/settings.json` — 全局应用设置

由应用程序自动维护。包含：

- `active_config` — 当前激活的教师配置文件绝对路径（空字符串时使用程序内置默认路径）
- `appearance` — 外观参数（字体、颜色、窗口缩放比例），作用于出勤码悬浮窗的显示效果

### 三文件关系图

```
settings.json
└── active_config ──────────────────────────→ <姓>_teacher_config.json
                                                ├── courses[].course_type ─→ school_config.json
                                                │                              └── course_types[]
                                                │                                   └── semester_id
                                                │                                       session_keys
                                                ├── courses[].slots[].weekday ─→ school_config.json
                                                │                                  └── semesters[]
                                                │                                       weekday_dates
                                                │                                       [weekday][回次]
                                                │                                       → 具体日期
                                                └── courses[].slots[].period ─→ school_config.json
                                                                                  └── periods[period]
                                                                                       → 开始时间
```
