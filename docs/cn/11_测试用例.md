| 项目 | 内容 |

**优先级定义**：P1 = 核心功能阻断 / P2 = 重要功能异常 / P3 = 次要行为验证

## 前置条件（全局）

所有测试用例共享以下前置条件：

- `config/school_config.json` 存在且格式合法（含2026年度日历、6个时限、4种课程类型）
- `config/teacher_A_config.json` 存在且格式合法（含5门课程及调课记录）
- Python 3.12 + PySide6 6.10.2 + pytest 9.0.2 + pytest-qt 4.5.0 已通过 `uv sync --group dev` 安装
- 执行命令：`uv run pytest -v`
