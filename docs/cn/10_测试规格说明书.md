## 2. 环境搭建步骤

```bash
# 1. 安装依赖（含 dev 组）
uv sync --group dev

# 2. 执行全部测试
uv run pytest -v

# 3. 执行单个测试文件
uv run pytest tests/test_scheduler.py -v
```

> `pyproject.toml` 中已配置 `pythonpath = ["src"]`，测试代码可直接 import `engine`、`models`、`gui` 包，无需手动设置 PYTHONPATH。

## 3. 测试策略

### 3.1 引擎层（纯函数单元测试）

`engine/` 模块不依赖任何 GUI 框架，所有函数均为纯函数（输入数据对象 → 返回数据对象）。测试策略：

- **Fixture 复用**：`school` 和 `teacher` fixture 使用 `scope="module"`，整个测试文件只加载一次配置，减少 I/O 开销
- **真实数据**：使用 `config/` 目录下的真实配置文件，而非合成数据，同时验证配置文件格式的正确性
- **边界值覆盖**：显示窗口的边界时刻（开始前1分钟 / 恰好开始 / 窗口内）均有对应测试用例
- **无 Qt 依赖**：引擎层测试不使用 `qtbot`，可在无图形环境下执行

### 3.2 GUI 层（控件状态测试）

`gui/` 模块依赖 PySide6。测试策略：

- **`qtbot.addWidget`**：所有 widget 通过 `qtbot.addWidget(win)` 注册，确保测试后自动清理
- **Fixture 隔离**：GUI widget 使用默认 `scope="function"`，每个测试用例获得全新实例，避免状态污染
- **非视觉验证**：通过读取 widget 属性（`.text()`、`.isVisible()`、`.count()`）验证状态，不做截图比对
- **结构验证为主**：验证对话框的控件结构（标签页数、列数、按钮集合），而非交互流程

## 4. 需求到测试点的映射

### 4.1 排课引擎

| 业务需求 | 测试点 | 测试函数 |
|---------|-------|---------|
| 春/秋学期课程应生成 14 次授课 | 件数验证 | `test_spring_course_14_sessions`、`test_autumn_course_14_sessions` |
| Q 系课程（双课位）应生成 14 次，编号连续 | 件数 + 编号 | `test_q1_course_14_occasions`、`test_q1_session_keys_sequential` |
| 双课位同周的两次课编号应跨 slot 连续递增 | 编号顺序 | `test_q1_week1_slot0_session01_slot1_session02` |
| 集中讲义课程不参与自动排课 | 空列表 | `test_intensive_returns_empty` |
| 特定课程的首课/末课日期应与学期日历一致 | 日期准确性 | `test_spring_thu1_first_date`、`test_spring_thu1_last_date`、`test_autumn_mon3_first_date` |
| Q1 双课位的曜日和时限应与 slot 定义一致 | 曜日/时限 | `test_q1_slot0_is_wednesday_period2`、`test_q1_slot1_is_friday_period3`、`test_q1_first_wednesday` |

### 4.2 显示窗口计算

| 业务需求 | 测试点 | 测试函数 |
|---------|-------|---------|
| 显示窗口 = 课程开始前 N 分钟至开始后 M 分钟 | 窗口边界计算 | `test_period1_window` |
| 当前时间在窗口内应返回该课程 | 命中逻辑 | `test_active_inside_window` |
| 当前时间恰好等于窗口开始时刻应命中 | 边界包含（闭区间） | `test_active_at_window_boundary_start` |
| 当前时间在窗口开始前应返回 None | 未命中 | `test_no_active_before_window` |
| 非上课曜日应返回 None | 非授课日 | `test_no_active_on_non_class_day` |

### 4.3 调课规则（Override）

| 业务需求 | 测试点 | 测试函数 |
|---------|-------|---------|
| skip：取消指定日期的课程，总次数减 1 | 件数、日期移除 | `test_skip_removes_one_date` |
| skip：剩余课程 session_key 从 01 起连续 | 编号重排 | `test_skip_renumbers_from_01` |
| skip：course_id 不匹配时无副作用 | 隔离性 | `test_skip_wrong_course_no_effect` |
| makeup：追加补课日期，总次数加 1 | 件数、日期添加 | `test_makeup_adds_date` |
| makeup：补课 session_key 为末尾编号 | 编号位置 | `test_makeup_session_key_is_last` |
| reschedule：原日期移除，新日期和时限替换 | 日期/时限替换 | `test_reschedule_replaces_date`、`test_reschedule_new_period` |
| 多课位课程的 skip 应跨 slot 重编号 | 多 slot 重排 | `test_q1_skip_renumbers_to_13` |
