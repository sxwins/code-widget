# 06 数据流图

## 1. 概述

应用程序遵循以下总体数据流：启动时加载配置文件，根据课程数据构建排课列表，然后运行每30秒触发一次的定时器循环，由循环判断是否显示或隐藏出勤码展示窗口。

整个应用以 `main()` 函数为入口，所有核心数据（配置、排课、临时出席码）均通过闭包（closure）在各内部函数之间共享，无全局状态类。

---

## 2. 启动流程（Startup Flow）

```
程序入口 main()
    │
    ├─1. 创建 QApplication
    │       app.setQuitOnLastWindowClosed(False) ← 关闭窗口不退出应用
    │       app.setApplicationName("CodeWidget")
    │       app.setWindowIcon(make_icon())
    │
    ├─2. 加载配置文件
    │   │
    │   ├─ _ensure_school_config(SCHOOL_CONFIG_PATH)
    │   │       └─ 若文件不存在 → 从内置模板（_MEIPASS）复制到 config/
    │   │
    │   ├─ _ensure_app_settings(APP_SETTINGS_PATH)
    │   │       └─ 若文件不存在 → 从内置模板复制，或写入默认 AppSettings()
    │   │
    │   ├─ app_settings = load_app_settings(APP_SETTINGS_PATH)
    │   │       → AppSettings
    │   │         .active_config  （teacher config 文件路径，可为空）
    │   │         .appearance     （外观设置）
    │   │
    │   ├─ teacher_path = app_settings.active_config
    │   │               或 DEFAULT_TEACHER_CONFIG  （若 active_config 为空）
    │   │
    │   ├─ _ensure_user_config(teacher_path)
    │   │       └─ 若文件不存在 → 从内置模板复制
    │   │
    │   ├─ school_config = load_school_config(SCHOOL_CONFIG_PATH)
    │   │       → SchoolConfig
    │   │         .periods[]       （课节时间段定义）
    │   │         .course_types[]  （课程类型定义）
    │   │         .semesters[]     （学期授课日信息）
    │   │
    │   └─ teacher_config = load_teacher_config(teacher_path)
    │           → TeacherConfig
    │             .courses[]          （课程列表）
    │             .overrides[]        （课程覆盖规则）
    │             .attendance_codes   （出席码字典）
    │             .window_position    （窗口位置）
    │             .settings           （pre/post_class_minutes 等）
    │           ※ 若加载失败 → 显示错误对话框并 sys.exit(1)
    │
    ├─3. 构建排课列表（_build_all_scheduled）
    │   │
    │   │  for course in teacher_config.courses:
    │   │      ├─ base = resolve_course_schedule(course, school_config)
    │   │      │       → List[ScheduledClass]（应用 override 前的基础排课）
    │   │      ├─ course_overrides = [ov for ov in overrides
    │   │      │                       if ov.course_id == course.id]
    │   │      └─ apply_overrides(base, course_overrides)
    │   │              → List[ScheduledClass]（override 后，session_key 重新编号）
    │   │
    │   all_scheduled = 所有课程的 ScheduledClass 合并列表
    │   _last_active  = [None]   ← 可变列表，作闭包单元格使用
    │   _temp_codes   = {}       ← 临时码内存缓存（仅存于内存，不持久化）
    │
    ├─4. 创建 UI 组件
    │   ├─ win  = AttendanceWindow()          ← 出席码展示窗口
    │   ├─ tray = TrayIcon(attendance_window=win)
    │   └─ tray.show()
    │
    ├─5. 恢复窗口位置
    │   win.move(teacher_config.window_position.x,
    │             teacher_config.window_position.y)
    │
    ├─6. 应用外观设置并显示窗口
    │   win.apply_appearance(app_settings.appearance)
    │   win.show()  ← 启动时始终显示窗口
    │
    ├─7. 连接信号（Signal → Slot）
    │   ├─ win.position_changed  → on_position_changed
    │   │       （窗口拖动后保存新坐标到 teacher_config.json）
    │   ├─ tray.open_config      → open_config
    │   │       （打开设置对话框 ConfigDialog）
    │   ├─ win.open_settings     → open_config
    │   ├─ tray.toggle_window    → toggle_window
    │   │       （切换窗口显示/隐藏）
    │   ├─ win.code_entered      → on_temp_code_entered
    │   │       （将临时码写入内存缓存，有效期30分钟）
    │   └─ win.code_cleared      → on_temp_code_cleared
    │           （从内存缓存中移除对应码，并刷新窗口显示）
    │
    ├─8. 启动定时器
    │   timer = QTimer()
    │   timer.timeout.connect(_tick)
    │   timer.start(30_000)  ← 每30秒触发
    │   _tick()              ← 启动时立即执行一次
    │
    └─9. app.exec()  ← 进入 Qt 事件循环（阻塞直到应用退出）
```

## 3. 定时器循环（_tick）

每隔30秒（以及启动时、配置保存时立即触发），`_tick()` 被调用一次。其核心设计是"仅在状态变化时更新 UI"，避免冗余的界面刷新。

```
每30秒（及启动时 / 配置保存时立即触发）:

_tick():
    │
    ├─ tc_settings = teacher_config.settings
    │               （若为 None，则使用默认 Settings()）
    │
    ├─ active = get_active_class(
    │               now(),          ← 当前时间
    │               all_scheduled,  ← 全部排课列表
    │               school_config,  ← 学校配置（课节时间等）
    │               tc_settings     ← 课前/课后缓冲分钟数
    │           )
    │           → ScheduledClass | None
    │
    ├─ active == _last_active[0]?
    │   │
    │   ├─ 是（状态未变）
    │   │   └─ 不做任何操作（避免冗余 UI 更新）
    │   │
    │   └─ 否（状态已变）
    │       ├─ _last_active[0] = active  ← 更新缓存状态
    │       │
    │       ├─ active is not None?
    │       │   │
    │       │   ├─ 是（当前有课）
    │       │   │   ├─ win.update_class(active, _code_for(active))
    │       │   │   │       ← 更新窗口显示的课程信息和出席码
    │       │   │   └─ win.show()  ← 显示窗口
    │       │   │
    │       │   └─ 否（当前无课）
    │       │       └─ win.hide()  ← 隐藏窗口
    │       │
    │       └─ tray.update_status(active)
    │               ← 更新系统托盘图标状态
```

## 4. 出席码解析（_code_for）

`_code_for` 实现了三级优先级查找：临时码（内存） > 已保存的码（JSON） > 空字符串。

```
_code_for(sc: ScheduledClass) → str:
    │
    key = f"{sc.course_id}_{sc.session_key}"
    │   （例如: "MATH101_3"，唯一标识某课程的第N次课）
    │
    ├─ key in _temp_codes?
    │   │
    │   ├─ 是，且 now() < expiry（未过期）
    │   │   └─ 返回临时码 temp_code  ← 最高优先级
    │   │
    │   └─ 是，但 now() >= expiry（已过期）
    │       ├─ del _temp_codes[key]  ← 清除过期缓存
    │       └─ 继续向下查找
    │
    ├─ key in teacher_config.attendance_codes?
    │   └─ 是 → 返回已保存的出席码  ← 次优先级
    │
    └─ 返回 ""  ← 最低优先级（空字符串，窗口显示"----"占位符）
```

临时码的生命周期：
```
用户在 AttendanceWindow 输入码
    │
    ├─ win.code_entered(key, code) 信号触发
    │       → on_temp_code_entered(key, code)
    │               _temp_codes[key] = (code, now() + timedelta(minutes=30))
    │
    ├─ 30分钟内: _code_for() 返回临时码
    │
    ├─ 30分钟后: _code_for() 访问时发现过期 → 自动清除 → 回退到已保存码
    │
    └─ 用户手动清除时:
            win.code_cleared(key) 信号触发
            → on_temp_code_cleared(key)
                    _temp_codes.pop(key, None)
                    win.update_class(_last_active[0], _code_for(_last_active[0]))
                            ← 立即刷新窗口以显示已保存码（或占位符）
```

## 5. 配置保存流程

```
用户在 ConfigDialog 点击"保存":
    │
    ├─ ConfigDialog 内部:
    │   ├─ save_teacher_config(teacher_config, save_path)
    │   │       → 写入 teacher_config.json（课程、override、出席码等）
    │   ├─ save_app_settings(app_settings, app_settings_path)
    │   │       → 写入 settings.json（外观设置、active_config 路径等）
    │   └─ 发出 config_saved 信号
    │
    └─ main.py 中的 on_config_saved() 响应信号:
            │
            ├─ all_scheduled = _build_all_scheduled(teacher_config, school_config)
            │       ← 重新构建全部排课（课程或 override 可能已变更）
            ├─ win.apply_appearance(app_settings.appearance)
            │       ← 应用新外观（字体、颜色等可能已变更）
            ├─ _last_active[0] = None
            │       ← 强制 _tick() 重新评估当前活动课程
            └─ _tick()  ← 立即触发一次，使 UI 反映最新配置
```

## 6. 加载新配置文件流程

```
用户在 ConfigDialog → 授業タブ 点击"設定を読み込む":
    │
    ├─ ConfigDialog 内部:
    │   ├─ 打开文件选择器（QFileDialog）
    │   ├─ 用户选择新的 teacher_config.json
    │   ├─ 解析所选文件（load_teacher_config）
    │   │       ← 验证文件格式是否合法
    │   └─ 发出 config_file_loaded(new_path: str) 信号
    │
    └─ main.py 中的 on_config_file_loaded(new_path) 响应信号:
            │
            ├─ teacher_path = Path(new_path)
            │       ← 更新闭包内的 teacher_path 变量
            ├─ app_settings.active_config = new_path
            │       ← 将新路径写入内存中的 AppSettings 对象
            ├─ save_app_settings(app_settings, APP_SETTINGS_PATH)
            │       ← 持久化到 settings.json，保证下次启动加载同一文件
            ├─ all_scheduled = _build_all_scheduled(teacher_config, school_config)
            │       ← 根据新配置重建排课列表
            ├─ win.apply_appearance(app_settings.appearance)
            │       ← 应用外观设置
            ├─ _last_active[0] = None
            │       ← 强制重新评估
            └─ _tick()  ← 立即触发
```

## 7. 文件路径解析

路径解析由两个辅助函数负责：`_resource()` 用于只读内置模板，`_user_data_dir()` 用于可写的用户数据目录。

```
_resource(rel) — 只读内置模板路径:
    │
    ├─ 打包后（sys.frozen == True）:
    │       → Path(sys._MEIPASS) / rel
    │         （PyInstaller 解压临时目录，只读）
    │
    └─ 开发模式:
            → Path(__file__).parent.parent / rel
              （即项目根目录）

_user_data_dir() — 可写用户数据目录:
    │
    ├─ 打包后 Windows:
    │       exe = Path(sys.executable)       ← e.g. C:\App\CodeWidget.exe
    │       → exe.parent                     ← C:\App\
    │
    ├─ 打包后 macOS（.app bundle）:
    │       exe = Path(sys.executable)
    │       路径结构:
    │         <somewhere>/
    │         └─ CodeWidget.app/
    │            └─ Contents/
    │               └─ MacOS/
    │                  └─ CodeWidget  ← sys.executable
    │       exe.parent       = MacOS/
    │       exe.parent.parent= Contents/
    │       .parent.parent   = CodeWidget.app/
    │       .parent.parent   = <somewhere>/  ← .app 所在文件夹（第4级）
    │       → 配置文件与 .app bundle 并排存放
    │
    └─ 开发模式:
            → Path(__file__).parent.parent
              （即项目根目录）

最终路径映射:
┌─────────────────────┬──────────────────────────────────────────────┐
│ 文件                │ 路径                                         │
├─────────────────────┼──────────────────────────────────────────────┤
│ school_config.json  │ <user_data_dir>/config/school_config.json    │
│ settings.json       │ <user_data_dir>/config/settings.json         │
│ teacher_config.json │ <user_data_dir>/config/teacher_config.json   │
│                     │ （或 AppSettings.active_config 所指路径）    │
├─────────────────────┼──────────────────────────────────────────────┤
│ 内置模板（只读）    │ sys._MEIPASS/config/school_config.json       │
│                     │ sys._MEIPASS/config/settings.json            │
│                     │ sys._MEIPASS/config/teacher_config.json      │
└─────────────────────┴──────────────────────────────────────────────┘

首次运行复制逻辑（_ensure_*）:
    目标文件不存在?
        ├─ 是 → 从内置模板复制到 user_data_dir/config/
        └─ 否 → 跳过（不覆盖用户已有数据）
```

## 8. 数据依赖关系图

```
磁盘文件                   内存模型                    UI / 引擎
────────────────────────────────────────────────────────────────────

settings.json
    │
    └─→ AppSettings
            ├─ active_config ────────────────────────→ teacher_config.json 路径
            └─ appearance ───────────────────────────→ AttendanceWindow 外观
                                                         （字体/颜色/透明度）

school_config.json
    │
    └─→ SchoolConfig
            ├─ periods[] ────────────────────────────→ get_active_class()
            │                                            时间窗口计算
            ├─ course_types[] ───────────────────────→ resolve_course_schedule()
            │                                            排课引擎
            └─ semesters[] ──────────────────────────→ 授课日解析

teacher_config.json
    │
    └─→ TeacherConfig
            ├─ courses[] ────────→ resolve_course_schedule()
            │                              │
            ├─ overrides[] ──────→ apply_overrides()
            │                              │
            │                     all_scheduled: List[ScheduledClass]
            │                              │
            │                     get_active_class(now())
            │                              │
            │                    active: ScheduledClass | None
            │                              │
            │                     ┌────────┴─────────┐
            │                     │                  │
            │                  有课（非None）       无课（None）
            │                     │                  │
            ├─ attendance_codes ─→ _code_for(active)  win.hide()
            │        +                    │
            │  _temp_codes{}              │
            │  （内存临时码）             ↓
            │                     win.update_class()
            │                     win.show()
            │
            ├─ window_position ──────────────────────→ win.move(x, y)
            │                                            窗口初始位置
            │
            └─ settings
                  ├─ pre_class_minutes  ──────────────→ get_active_class()
                  └─ post_class_minutes ──────────────→ 课前/课后显示时间窗口

信号流（双向）:
    win.position_changed(x, y)  →  on_position_changed
                                        └→ save_teacher_config() → 磁盘

    win.code_entered(key, code) →  on_temp_code_entered
                                        └→ _temp_codes[key] = (code, expiry)

    win.code_cleared(key)       →  on_temp_code_cleared
                                        └→ _temp_codes.pop(key)
                                           win.update_class(...)

    tray.toggle_window          →  toggle_window
                                        └→ win.show() / win.hide()

    tray.open_config            →  open_config → ConfigDialog
    win.open_settings           →  open_config → ConfigDialog

    ConfigDialog.config_saved        →  on_config_saved  → _tick()
    ConfigDialog.config_file_loaded  →  on_config_file_loaded → _tick()
```

## 9. 完整数据流时序图

```
时间轴 →

启动
 │
 ├── [磁盘] school_config.json ──读取──→ SchoolConfig
 ├── [磁盘] settings.json ──────读取──→ AppSettings
 ├── [磁盘] teacher_config.json ─读取──→ TeacherConfig
 │
 ├── SchoolConfig + TeacherConfig → _build_all_scheduled()
 │                                        → all_scheduled[]
 │
 ├── AttendanceWindow.show()
 │
 ├── _tick()  ←─────────────────────────────────────────────┐
 │       │                                                   │
 │       ├── get_active_class(now(), all_scheduled, ...)     │
 │       │       → active                                    │
 │       │                                                   │
 │       ├── active 变化?                                    │
 │       │       └── 是 → update UI                         │
 │       │               ├── active != None:                │
 │       │               │     _code_for(active) → code     │
 │       │               │     win.update_class(active, code)│
 │       │               │     win.show()                   │
 │       │               └── active == None:                │
 │       │                     win.hide()                   │
 │       └── tray.update_status(active)                     │
 │                                                          │
 ├── [每30秒] QTimer.timeout ──────────────────────────────→┘
 │
 ├── [用户拖动窗口]
 │       win.position_changed(x, y)
 │           → save_teacher_config() → [磁盘] teacher_config.json
 │
 ├── [用户输入临时码]
 │       win.code_entered(key, code)
 │           → _temp_codes[key] = (code, now()+30min)
 │           （仅内存，不写磁盘）
 │
 ├── [用户打开设置并保存]
 │       ConfigDialog.config_saved
 │           → save_teacher_config() → [磁盘]
 │           → save_app_settings()   → [磁盘]
 │           → _build_all_scheduled() → all_scheduled[]（更新）
 │           → _tick()  ← 立即触发
 │
 └── [用户加载新配置文件]
         ConfigDialog.config_file_loaded(new_path)
             → app_settings.active_config = new_path
             → save_app_settings() → [磁盘] settings.json
             → _build_all_scheduled() → all_scheduled[]（更新）
             → _tick()  ← 立即触发
```
