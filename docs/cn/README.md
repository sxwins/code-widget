# CodeWidget 中文文档索引

## 文档目的

本文档集面向**重写团队**，旨在无需阅读源代码即可完整理解 CodeWidget（出勤码展示工具）的业务逻辑、架构设计和实现细节，从而用其他语言或框架重新实现该应用。

## 应用概述

CodeWidget 是一款桌面工具，供教师在上课期间展示出勤码。核心行为：

- 在课程的**展示窗口**内（课前 10 分钟至课后 30 分钟），自动弹出一个始终置顶的小型浮动窗口，显示当堂课的出勤码
- 管理教师的课程信息、学期排课计划，以及调课、停课、补课等临时调整
- 构建于 Python 3.12 + PySide6，打包为 Windows `.exe` 和 macOS `.app`

定义所有 JSON 配置文件的字段、类型、约束和示例，包括教师配置文件、课程表、学期定义及调整记录的完整 Schema。
