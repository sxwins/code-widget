## 1. 简介

### 1.1 功能概述

CodeWidget 是一款桌面悬浮工具，专为大学教师设计。它会在课程开始前自动弹出悬浮窗口，显示当节课的出席码；课程结束后自动隐藏，全程无需手动操作。

主要功能：

- 按学期日历自动计算上课时间，到点自动显示出席码
- 每节课预先分配出席码，支持批量生成或手动修改
- 支持停课、补课、调课等特殊安排
- 悬浮窗口始终置顶，位置可拖动并记忆
- 通过系统托盘图标操作，不占用任务栏

### 1.2 运行环境

- **操作系统**：Windows 10 / 11
- **安装方式**：单文件 `.exe`，无需安装程序
- **依赖**：无（所有依赖已打包）

## 2. 初次配置

### 2.1 文件放置

将 `CodeWidget.exe` 放置到任意文件夹。首次运行后，程序会自动在同目录下创建 `config/` 文件夹，包含以下文件：

| 文件 | 用途 |
|------|------|
| `config/school_config.json` | 学校日历（学期日期、节次时间、假日） |
| `config/teacher_config.json` | 教师课程数据（课程、出席码、调整记录） |
| `config/settings.json` | 外观设置（字体、颜色、窗口大小） |

> 所有配置文件均为纯文本 JSON 格式，可用记事本直接编辑。

### 2.2 确认学校日历（school_config.json）

`school_config.json` 预置了学校的标准日历，包含学期起止日期、各节次时间和法定假日。如需调整（例如新学年替换），直接替换该文件即可，无需重新安装程序。

各节次默认时间如下：

| 节次 | 开始时间 | 结束时间 |
|------|---------|---------|
| 1限 | 08:50 | 10:30 |
| 2限 | 10:40 | 12:20 |
| 3限 | 13:10 | 14:50 |
| 4限 | 15:00 | 16:40 |
| 5限 | 16:50 | 18:30 |
| 6限 | 18:40 | 20:20 |

### 2.3 注册课程（设置对话框）

双击托盘图标，或右键托盘图标选择 **設定…** 打开设置对话框。

在 **授業** 标签页中，可以查看和管理已注册的课程列表。

![设置对话框 — 授業标签页](screenshots_raw/02_授業标签页.png)

操作步骤：

1. 点击 **追加** 新建课程
2. 填写课程名称、课程类型（spring / autumn / Q1〜Q4）、上课星期和节次
3. 点击 **保存**

> **設定を読み込む**：可加载其他教师的配置文件，方便多位教师共用同一台电脑。

课程信息填写完成后，切换到 **日程プレビュー** 标签页，可查看该学期完整的排课日程，确认日期正确。

### 2.4 设置出席码

在 **日程プレビュー** 标签页中，每节课右侧有出席码输入框。

![日程プレビュー标签页](screenshots_raw/03_日程プレビュー标签页.png)

支持以下操作：

- **手动输入**：直接点击输入框填写4位数字
- **批量生成**：点击 **コード生成** 按钮，为所有未设置的课次自动生成随机码

填写完毕后点击 **保存**，出席码写入配置文件。

## 3. 日常使用

### 3.1 启动与退出

**启动**：双击 `CodeWidget.exe`。程序启动后在系统托盘显示图标，不出现在任务栏。

**退出**：右键托盘图标 → 选择 **終了**。

> 程序启动后保持后台运行，无需每次课前手动操作。

### 3.2 出席码窗口说明

在上课时间窗口内（默认：课程开始前10分钟至开始后30分钟），出席码悬浮窗口自动弹出。

![出席码悬浮窗口](screenshots_raw/01_出勤码悬浮窗口.png)

窗口中央以大字显示4位出席码，供学生扫视记录。

窗口特性：
- 始终置顶显示，不被其他窗口遮挡
- 可用鼠标拖动到屏幕任意位置，位置在重启后保持记忆
- 课程结束（时间窗口过期）后自动隐藏

### 3.3 临时码的输入与清除

如需临时展示不同的出席码（例如临时变更），可在不修改配置的情况下输入临时码：

1. 右键出席码窗口 → 选择 **入力**
2. 直接在窗口中输入新的出席码，按回车确认
3. 临时码有效期为 **30分钟**，到期后自动恢复显示正式出席码

**清除临时码**：右键出席码窗口 → 选择 **クリア**，立即恢复正式出席码。

> 临时码仅保存在内存中，重启程序后自动消失。

### 3.4 窗口的显示与隐藏

| 操作 | 方法 |
|------|------|
| 隐藏窗口 | 右键出席码窗口 → **隠す**，或右键托盘图标 → **ウィンドウを隠す** |
| 重新显示 | 右键托盘图标 → **ウィンドウを表示**，或单击托盘图标 |

> 手动隐藏后，下次课程开始时窗口不会自动重新显示，直到重启程序或手动点击显示。

## 4. 课程调整管理

在 **設定** → **調整** 标签页中，可管理停课、补课和调课记录。

![調整标签页](screenshots_raw/05_調整标签页.png)

### 4.1 登记停课

1. 点击 **調整を追加**
2. 选择课程，在调整类型中选择 **休講**
3. 选择停课日期，点击 **OK**

该日期的课次将从日程中删除，后续课次自动重新编号。

### 4.2 登记补课

1. 点击 **調整を追加**
2. 选择课程，在调整类型中选择 **補講**
3. 选择补课日期和节次，点击 **OK**

补课日期将作为额外课次添加到日程末尾。

### 4.3 登记调课（振替）

调课将某节课从原日期移至新日期。

1. 点击 **調整を追加**
2. 选择课程，在调整类型中选择 **振替**

![調整を追加对话框](screenshots_raw/04_調整を追加对话框.png)

3. 在 **対象回** 中选择要移动的课次
4. 设置 **新日付**（新日期）和 **新時限**（新节次）
5. 点击 **OK**

原课次从原日期移除，在新日期重新安排，出席码保持对应关系。

### 4.4 编辑与删除调整

- 选中列表中的调整记录后，点击 **編集** 可修改（仅调课类型支持编辑）
- 点击 **削除** 删除选中的调整记录

### 4.5 日程预览确认

所有调整完成后，切换到 **日程プレビュー** 标签页确认最终日程，检查日期、节次和出席码是否符合预期，再点击 **保存**。

## 5. 外观自定义

在 **設定** → **外観** 标签页中，可调整出席码窗口的视觉样式。

![外観标签页](screenshots_raw/06_外観标签页.png)

| 设置项 | 说明 |
|--------|------|
| 出席コード — フォント | 出席码字体族 |
| 出席コード — サイズ | 出席码字号 |
| 文字色 | 出席码数字颜色（点击色块选色） |
| 背景色 | 窗口背景颜色 |
| 枠色 | 窗口圆角边框颜色 |
| 科目名 — フォント | 课程名称字体族 |
| 科目名 — サイズ | 课程名称字号 |
| ウィンドウサイズ | 整体缩放比例（点击 **＋** / **−** 以10%为单位调整） |

修改后点击 **保存**，出席码窗口立即更新显示效果。

## 6. 故障排除

### 6.1 窗口未显示

**现象**：处于上课时间，但出席码窗口没有出现。

**原因与处理**：

| 原因 | 处理方法 |
|------|---------|
| 课程未正确注册 | 打开设置对话框，在日程预览中确认该日期是否有排课 |
| 时间窗口设置过窄 | 在授業标签页确认「開始前表示」（默认10分钟）和「終了後表示」（默认30分钟） |
| 电脑从休眠中唤醒 | 程序检测到唤醒后会在30秒内自动刷新；若仍未显示，单击一次托盘图标手动触发 |
| 窗口被手动隐藏 | 右键托盘图标 → **ウィンドウを表示** |

### 6.2 出席码未更新

**现象**：保存了新的出席码，但悬浮窗口仍显示旧码。

**处理方法**：

1. 确认已点击设置对话框的 **保存** 按钮
2. 保存后窗口会在几秒内自动刷新；若未刷新，重启程序

### 6.3 窗口消失在屏幕外

**现象**：拔掉外接显示器后，出席码窗口看不见，也无法拖回。

**处理方法**：

重启程序。程序启动时会自动检测窗口位置，若保存的位置已超出当前屏幕范围，会自动将窗口重置到主屏幕左上角。

### 6.4 更换新版本后托盘图标不显示

**现象**：替换 `CodeWidget.exe` 后，系统托盘图标未出现在通知区域。

**处理方法**：

Windows 按可执行文件路径记忆托盘图标的显示设置。只要每次将新版 `CodeWidget.exe` 放在**相同路径**下覆盖替换，设置会自动保留。

若路径已变更，需重新在 Windows 设置中启用：
> 设置 → 个性化 → 任务栏 → 其他系统托盘图标 → 找到 CodeWidget → 开启
