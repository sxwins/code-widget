# CodeWidget — 界面规格说明书

> 版本：1.0.0　　撰写日期：2026-03-03　　对应源码版本：master (ab889cf)

本文档是 CodeWidget 应用程序的完整 UI 规格说明。目标读者为重写团队，阅读本文档后，无需查阅任何源代码即可完整还原所有 UI 组件的外观、交互与行为。

---

## 1. 概述

CodeWidget 的 UI 由三个独立组件构成：

| 编号 | 组件名 | 类名 | 职责 |
|------|--------|------|------|
| 1 | 出勤码展示窗口 | `AttendanceWindow` | 浮动覆盖层，全时置顶显示当前课程的出席码 |
| 2 | 系统托盘图标 | `TrayIcon` | 驻留在系统通知区，提供快捷菜单与状态提示 |
| 3 | 设置对话框 | `ConfigDialog` | 5 标签页配置界面，管理课程、排课预览、调课、外观、关于信息 |

三个组件之间通过 Qt 信号/槽机制通信，不直接相互调用方法。主控逻辑位于 `main.py`，由定时器（每 30 秒）驱动状态刷新。

## 2. 出勤码展示窗口（AttendanceWindow）

### 2.1 窗口特性

| 属性 | 值 / 说明 |
|------|-----------|
| 窗口类型 | 无边框（`FramelessWindowHint`）+ 始终置顶（`WindowStaysOnTopHint`） |
| 平台标志 | Windows/Linux: 追加 `Tool` 标志，窗口不显示在任务栏及 Alt+Tab 列表中；macOS: 不加 `Tool` 标志（加了会导致窗口被隐藏） |
| 基础尺寸 | 300 × 125 px（100% 缩放时） |
| 可缩放范围 | 30%–300%，步长 10%；尺寸随 `window_scale` 线性缩放 |
| 背景 | `WA_TranslucentBackground`（Qt 透明背景属性），实际背景在 `paintEvent` 中手动绘制圆角矩形 |
| 圆角半径 | 基础值 12 px；缩放后 = `max(4, int(12 × scale))`，最小不低于 4 px |
| 边框宽度 | 1.5 px |
| 默认背景色 | `#ffffff`（白色），可通过外观设置修改 |
| 默认边框色 | `#90CAF9`（浅蓝色），可通过外观设置修改 |
| 可拖动 | 左键按住拖动；拖动时实时更新位置；鼠标释放时发出 `position_changed` 信号并保存坐标到 `teacher_config.json` |
| 初始状态 | 隐藏（`hide()`）；`main.py` 在启动时调用 `win.show()` 使其可见 |
| 初始位置 | 若 `teacher_config.window_position` 有保存值，则恢复到该位置 |

### 2.2 布局（ASCII 示意图）

```
+------------------------------------------+  ← 圆角矩形边框（border_color，1.5px）
|  [APP图标]  课程名称        第 XX 回       |  ← 顶部行
|                                          |  ← 弹性空间（addStretch）
|                ABCD                      |  ← 出席码（居中，大字体，只读 QLineEdit）
|                                          |  ← 弹性空间（addStretch）
+------------------------------------------+
  背景填充色 = code_bg_color
  外边距: 左右 10px，上 8px，下 6px
  内部间距: 0px
```

**顶部行（QHBoxLayout）详细说明：**

```
[APP图标 18×18]  [课程名称 stretch=1]  [第XX回（右对齐）]
```

- APP 图标：`QLabel`，固定大小 18×18 px，显示应用图标（`make_icon(16).pixmap(16, 16)`）
- 课程名称标签（`label_course`）：`QLabel`，字体粗体 11pt，水平方向弹性拉伸（`stretch=1`）
- 课时标签（`label_session`）：`QLabel`，10pt 普通字体，文本格式为 `"第{session_key}回"`，右对齐 + 垂直居中（`AlignRight | AlignVCenter`）

**出席码输入框（`code_edit`）：**

| 属性 | 值 |
|------|----|
| 控件类型 | `QLineEdit` |
| 默认字体 | `Courier New`，72pt，粗体 |
| 对齐方式 | 水平居中（`AlignCenter`） |
| 初始状态 | 只读（`setReadOnly(True)`） |
| 占位符文本 | `"----"`（无出席码时显示） |
| 边框 | 无（`setFrame(False)`） |
| 文字颜色 | 由 `code_color` 设置（默认 `#00ff7f`） |
| 背景色 | transparent（通过 stylesheet 设为透明） |
| 右键菜单 | 禁用（`NoContextMenu`） |

### 2.3 绘制机制（paintEvent）

在 `paintEvent` 中执行以下绘制步骤（抗锯齿开启）：

1. 将 `self.rect()` 向内缩进 1px（上下左右各缩 1px），得到绘制区域
2. 用 `code_bg_color` 填充圆角矩形（无边框画笔）
3. 用 `border_color` 绘制圆角矩形外边框（宽度 1.5px，无填充）

### 2.4 右键菜单（ContextMenu）

右键单击窗口任意位置弹出上下文菜单（包括出席码输入框区域，因为输入框的右键菜单已被禁用）：

```
┌──────────────┐
│  入力        │  → 使 code_edit 变为可编辑状态
│  クリア      │  → 清空出席码
├──────────────┤  ← 分隔线
│  設定        │  → 打开 ConfigDialog
│  隠す        │  → 隐藏窗口
├──────────────┤  ← 分隔线
│  終了        │  → 退出应用（QApplication.quit()）
└──────────────┘
```

各菜单项详细行为：

| 菜单项 | 行为 |
|--------|------|
| 入力 | 调用 `_on_edit()`：`code_edit.setReadOnly(False)` → `setFocus()` → `selectAll()` |
| クリア | 调用 `_on_clear_btn()`：`code_edit.setReadOnly(True)`；若有当前课程，发出 `code_cleared(key)` 信号；否则直接 `code_edit.clear()` |
| 設定 | 发出 `open_settings` 信号（由 `main.py` 接收并打开 ConfigDialog） |
| 隠す | `self.hide()` 隐藏窗口 |
| 終了 | `QApplication.instance().quit()` 退出整个应用 |

### 2.5 出席码输入流程

```
用户右键 → 选择"入力"
    ↓
code_edit.setReadOnly(False)
code_edit.setFocus()
code_edit.selectAll()
    ↓
用户输入或粘贴码，按 Enter（或点击其他区域）
    ↓
editingFinished 信号触发 → _on_editing_finished()
    ↓
code_edit.setReadOnly(True)
    ↓
若 _current_sc 不为 None：
    key = "{course_id}_{session_key}"
    发出 code_entered(key, code_edit.text()) 信号
    ↓
main.py 接收：将 (code, now() + 30分钟) 存入内存字典 _temp_codes[key]
```

### 2.6 出席码优先级（来自 main.py）

每次调用 `_code_for(sc)` 时，按以下优先级返回出席码：

1. **内存临时码**：`_temp_codes[key]` 存在且未过期（TTL 30 分钟）→ 返回临时码，并在过期时自动从字典中删除
2. **配置文件保存码**：`teacher_config.attendance_codes.get(key, "")` → 返回已保存的码
3. **空字符串**：`""` → `code_edit` 显示占位符 `"----"`

### 2.7 信号规格

| 信号名 | 参数类型 | 触发时机 |
|--------|----------|---------|
| `position_changed` | `(int x, int y)` | 鼠标左键释放，且之前处于拖动状态 |
| `open_settings` | 无 | 右键菜单 → 設定 |
| `code_entered` | `(str key, str code)` | 输入完成（editingFinished），key 格式：`"{course_id}_{session_key}"` |
| `code_cleared` | `(str key)` | 右键菜单 → クリア，且有当前课程 |

### 2.8 公共 API

**`apply_appearance(appearance: Appearance)`**

按以下顺序应用外观设置：

1. 设置 `code_edit` 字体：`QFont(code_font_family, code_font_size)`，粗体
2. 设置 `code_edit` stylesheet：`color: {code_color}; background-color: transparent; border: none;`
3. 设置窗口背景色：`_bg_color = QColor(code_bg_color)`
4. 设置边框色：`_border_color = border_color`
5. 若 `course_font_family` 非空：设置 `label_course` 字体为 `QFont(course_font_family, course_font_size)`，粗体
6. 计算缩放后窗口尺寸：`scale = window_scale / 100.0`；`setFixedSize(int(300 * scale), int(125 * scale))`
7. 计算圆角半径：`_corner_radius = max(4, int(12 * scale))`
8. 调用 `self.update()` 触发重绘

**`update_class(sc: ScheduledClass, code: str = "")`**

1. 保存 `_current_sc = sc`
2. `label_course.setText(sc.course_name)`
3. `label_session.setText(f"第{sc.session_key}回")`
4. `code_edit.setText(code)`
5. `code_edit.setReadOnly(True)`

### 2.9 拖动机制

| 事件 | 行为 |
|------|------|
| `mousePressEvent`（左键） | `_drag_active = True`；记录鼠标全局坐标与窗口左上角的偏移 |
| `mouseMoveEvent`（拖动中） | `_drag_active` 为 True 时，调用 `self.move(new_x, new_y)` 实时移动窗口 |
| `mouseReleaseEvent`（左键释放） | `_drag_active = False`；发出 `position_changed(self.x(), self.y())` |

## 3. 系统托盘图标（TrayIcon）

### 3.1 概述

`TrayIcon` 继承自 `QSystemTrayIcon`。图标使用 `make_icon()` 生成（应用通用图标）。托盘图标在 `main.py` 启动时通过 `tray.show()` 显示，全程保持可见。

### 3.2 托盘右键菜单

```
┌──────────────────────────┐
│  ウィンドウを表示/隠す    │  ← 动态文本（见下表）
│  設定…                   │
├──────────────────────────┤  ← 分隔线
│  終了                     │
└──────────────────────────┘
```

**动态菜单项文本规则（`_action_toggle`）：**

| 条件 | 菜单文本 |
|------|---------|
| 无活动课程（`sc is None`） | `"ウィンドウを表示"` |
| 有活动课程 + 窗口当前可见 | `"ウィンドウを隠す"` |
| 有活动课程 + 窗口当前隐藏 | `"ウィンドウを表示"` |

注意：文本更新在 `update_status(sc)` 方法中完成，该方法由 `main.py` 在状态变化时调用。

**各菜单项动作：**

| 菜单项 | 动作 |
|--------|------|
| ウィンドウを表示/隠す | 发出 `toggle_window` 信号 |
| 設定… | 发出 `open_config` 信号 |
| 終了 | `QApplication.instance().quit()` |

### 3.3 ToolTip（提示文本）

| 状态 | 提示文本 |
|------|---------|
| 无活动课程 | `"CodeWidget — No active class"` |
| 有活动课程 | `"CodeWidget — {sc.course_name}  第{sc.session_key}回"` |

提示文本同样在 `update_status(sc)` 中更新。

### 3.4 单击行为

托盘图标激活触发机制（`activated` 信号）：

- 仅响应 `Trigger`（单击）类型的激活事件
- 单击时发出 `toggle_window` 信号
- `main.py` 接收后：若窗口可见则 `hide()`，若隐藏则先刷新内容再 `show()`

双击、中键等其他激活方式不处理。

### 3.5 信号规格

| 信号名 | 触发时机 |
|--------|---------|
| `open_config` | 菜单 → 設定… |
| `toggle_window` | 菜单 → ウィンドウ切换 或 单击托盘图标 |

### 3.6 公共 API

**`update_status(sc: ScheduledClass | None)`**

- 参数为 `None`：设置 ToolTip 为 "No active class"，菜单文本为 "ウィンドウを表示"
- 参数为有效课程：设置 ToolTip 为课程信息；根据 `_attendance_window.isVisible()` 决定菜单文本

### 4.1 窗口基本属性

| 属性 | 值 |
|------|----|
| 窗口标题 | `"CodeWidget 設定"` |

### 4.2 整体布局

```
+-------------------------------------------------------+
|  [授業] [日程プレビュー] [調整] [外観] [About]        |  ← QTabWidget
|                                                       |
|  （标签页内容区域，随标签切换）                         |
```

底部按钮行：
- `保存` 按钮：点击触发 `_on_save()`

| 切换目标标签（index） | 刷新操作 |
|----------------------|---------|
| 1（日程プレビュー） | `_refresh_preview()` |
| 2（調整） | `_populate_adj_table()` |

### 4.4 信号规格

| 信号名 | 参数类型 | 触发时机 |
|--------|----------|---------|
| `config_saved` | 无 | 点击"保存"，写入成功后 |
| `config_file_loaded` | `str`（新配置文件路径） | 通过"設定を読み込む"加载新配置后 |

## 5. 标签页1：授業（课程管理）

### 5.1 课程表格

表格类型：`QTableWidget`，5 列，不可编辑，行选择模式，无网格线。

选中行高亮样式：`background-color: #BBDEFB; color: black;`

| 列序 | 列标题 | 列宽策略 | 内容说明 |
|------|--------|---------|---------|
| 0 | ID | ResizeToContents | 课程唯一 ID |
| 1 | 授業名 | 弹性（65% 剩余空间） | 课程名称 |
| 2 | 年度 | ResizeToContents × 1.2 | 从 `school_config.course_types[course_type].semester_id` 提取年度部分（最后一个 `_` 之后的字符串） |
| 3 | 種別 | ResizeToContents × 1.2 | 课程类型（spring/autumn/Q1–Q4） |
| 4 | スロット | 弹性（35% 剩余空间） | 时段字符串，格式如 `"水3限"` 或 `"水2限, 金3限"`（多时段用 `", "` 连接） |

时段标签格式：`"{曜日}{period}限"`，曜日映射：Monday→月、Tuesday→火、Wednesday→水、Thursday→木、Friday→金、Saturday→土、Sunday→日

列宽调整策略（延迟执行，使用 `QTimer.singleShot(0, ...)`）：
- 列 0（ID）和列 2、3（年度、種別）先按内容自动调整，再固定为自然宽度的 1.2 倍
- 列 1（授業名）= 剩余空间 × 65%，最小 80px
- 列 4（スロット）= 剩余空间 × 35%，最小 60px

### 5.2 按钮行

```
[設定を読み込む] [追加] [編集] [削除]   <弹性空间>   [衝突検出]
```

| 按钮 | 触发动作 |
|------|---------|
| 設定を読み込む | 打开文件选择对话框，加载新的 `teacher_config.json` |
| 追加 | 打开 `CourseEditDialog`（新建模式），接受后追加到课程列表 |
| 編集 | 打开 `CourseEditDialog`（编辑模式，传入选中课程），接受后替换 |
| 削除 | 弹出确认对话框 `"「{course.name}」を削除しますか？"` (Yes/No)，确认后删除 |
| 衝突検出 | 检测同日时间段重叠，弹出结果对话框 |

**加载配置文件流程（設定を読み込む）：**

1. `QFileDialog.getOpenFileName` 过滤条件：`"JSON (*.json)"`
2. 读取成功后，将新配置数据就地更新到原配置对象（`_orig_teacher.__dict__.update(...)` 使 `main.py` 的引用同步）
3. 更新 `app_settings.active_config`
4. 刷新授業、日程プレビュー、調整三个标签页的显示
5. 发出 `config_file_loaded(path)` 信号

读取失败时显示错误对话框：`"設定の読み込みに失敗しました。\n\n{exc}"`

**衝突検出逻辑：**

- 对所有课程应用 override 后的排课，按日期分组
- 同日不同课程之间检测时间窗口重叠（使用 `school_config.periods` 中的起止时间）
- 自定义时间（custom_start）的课程，以 start → start + 90分钟 作为时间窗口
- 每对冲突只报告一次（按 (date, courseA_id, courseB_id) 去重）
- 有冲突：`QMessageBox.warning`，列出每条冲突信息：`"・{date}  {HH:MM}〜:  {A课程名}（第X回）と {B课程名}（第Y回）"`
- 无冲突：`QMessageBox.information`，显示 `"衝突は検出されませんでした。"`

| 金曜 | Friday |

## 7. 标签页2：日程プレビュー（排课预览）

### 7.1 布局

```
[课程选择 QComboBox ▼                     ]

┌────┬────────────┬────┬──────┬──────────┐
│ 回 │ 日付       │曜日│ 時限 │ 出席コード│
├────┼────────────┼────┼──────┼──────────┤
│ 1  │ 2026-04-08 │ 水  │ 3限  │ AB12     │
│ 2  │ 2026-04-15 │ 水  │ 3限  │          │
│ ...│            │    │      │          │
└────┴────────────┴────┴──────┴──────────┘

[コード生成]   <弹性空间>
```

### 7.2 课程选择 ComboBox

- 列出 `teacher_config.courses` 中所有课程（显示名称，userData 为课程 ID）
- 切换课程时刷新预览表格

### 7.3 预览表格

表格类型：`QTableWidget`，5 列，所有列等宽弹性拉伸。

| 列序 | 列标题 | 可否编辑 | 内容格式 |
|------|--------|---------|---------|
| 0 | 回 | 否 | session_key（第几回，字符串） |
| 1 | 日付 | 否 | `YYYY-MM-DD` |
| 2 | 曜日 | 否 | 日文曜日（月/火/水/木/金） |
| 3 | 時限 | 否 | 标准课时：`"{period}限"`；自定义时间：`"{HH:MM}-{结束HH:MM}"`（结束 = 开始 + 100 分钟） |
| 4 | 出席コード | 是（双击编辑） | 已保存的出席码，无则空白 |

所有单元格内容均居中对齐。

仅第 4 列（出席コード）可编辑，通过 `_CodeColumnDelegate` 实现（`createEditor` 对非第4列返回 `None`）。

编辑触发方式：双击（`DoubleClicked`）。

**内联编辑行为（`_on_code_changed`）：**
- 仅处理第 4 列的变更
- 非空值：更新 `teacher_config.attendance_codes["{course_id}_{session_key}"]`
- 空值：从 `attendance_codes` 中删除对应键

### 7.4 コード生成按钮

- 为当前选中课程的所有课次生成随机 4 位数字码（`f"{random.randint(0, 9999):04d}"`，即 0000–9999）
- 写入 `teacher_config.attendance_codes`
- 调用 `_refresh_preview()` 刷新显示

### 7.5 数据来源

显示的是应用所有 override 后的实际排课（`apply_overrides(base, course_overrides)`），按日期排序，不是原始课表。

## 12. 保存逻辑（_on_save）

点击"保存"按钮时，按以下顺序执行：

```
1. 将 teacher_config（课程、码、位置等）写入 teacher_config.json
   → save_teacher_config(self.teacher_config, self.save_path)

2. 将 teacher_config 变更同步到原始对象（使 main.py 的引用立即生效）
   → self._orig_teacher.__dict__.update(self.teacher_config.__dict__)

3. 从控件读取外观设置，写入 app_settings.appearance：
   - code_font_family  ← _font_combo.currentFont().family()
   - code_font_size    ← _size_spin.value()
   - course_font_family ← _course_font_combo.currentFont().family()
   - course_font_size  ← _course_size_spin.value()
   - window_scale      ← _window_scale（内部变量）
   （code_color、code_bg_color、border_color 在颜色选择时实时写入，此处无需再读取）

4. 将 app_settings 写入 settings.json
   → save_app_settings(self.app_settings, self.app_settings_path)

5. 同步到原始对象
   → self._orig_app_settings.__dict__.update(self.app_settings.__dict__)

6. 发出 config_saved 信号
   → main.py 接收：重建排课 + 应用外观 + 立即触发 _tick()

7. 保存按钮变为 "✓ 保存完了" 并禁用，2秒后恢复
```

## 13. 应用状态机

### 13.1 启动流程

```
[程序启动]
    ↓
加载 school_config.json、settings.json、teacher_config.json
    ↓
_build_all_scheduled() 构建所有课程的排课列表（含 overrides）
    ↓
创建 AttendanceWindow、TrayIcon
    ↓
恢复窗口位置（若有保存值）
    ↓
apply_appearance()（应用外观设置）
    ↓
win.show()（初始显示窗口）
    ↓
启动 30 秒定时器
    ↓
立即调用 _tick()（不等第一次定时器触发）
```

### 13.2 定时器驱动的状态更新（_tick）

每 30 秒执行一次（启动时立即执行一次）：

```
_tick():
    获取当前时间（now()）
    active = get_active_class(now, all_scheduled, school_config, tc_settings)

    若 active == _last_active[0]：
        → 无变化，直接返回（避免不必要的 UI 刷新）

    否则：
        _last_active[0] = active

        若 active 不为 None：
            code = _code_for(active)
            win.update_class(active, code)
            win.show()

        若 active 为 None：
            win.hide()

        tray.update_status(active)
```

### 13.3 窗口显示状态变化一览

| 触发事件 | AttendanceWindow 行为 | TrayIcon 更新 |
|---------|----------------------|--------------|
| 进入活动课时段（_tick 检测到） | `update_class()` + `show()` | `update_status(active_sc)` |
| 离开活动课时段（_tick 检测到） | `hide()` | `update_status(None)` |
| 托盘单击 / 菜单「ウィンドウ切换」 | 若可见则 `hide()`；若隐藏则（若有活动课则刷新内容后）`show()` | `update_status(_last_active)` |
| 窗口右键 → 隠す | `hide()` | （不更新） |
| 窗口右键 → 終了 | 退出 | — |
| 保存配置后 | 重建排课 + `apply_appearance()` + `_tick()` | 随 `_tick()` 更新 |
| 加载新配置文件后 | 同上 | 同上 |

### 13.4 状态转换图（简化）

```
                        [启动]
                           |
                     初始化 + show()
                           |
                    ┌──────▼──────┐
          ┌─────────│   等待中    │─────────┐
          │         └──────┬──────┘         │
          │                │ 定时器 / 配置保存  │
          │                ▼                 │
          │       get_active_class()         │
          │                │                 │
          │    ┌───────────┴───────────┐     │
          │    │ 有活动课              │无活动课│
          │    ▼                       ▼     │
          │  show() +               hide() ──┘
          │ update_class()
          │    │
          │    │ 用户操作：隠す / 托盘切换
          └────┴──→ 手动 show()/hide()（不改变 _last_active）
```
