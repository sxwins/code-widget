# 04 数据格式规格

## 1. 概述

CodeWidget 使用三个 JSON 配置文件：

| 文件名 | 作用范围 | 说明 |
|--------|----------|------|
| `school_config.json` | 全校共用 | 时限定义、课程类型、学期日程。所有教师共享同一份文件。 |
| `<教师名>_teacher_config.json` | 每位教师独立 | 课程列表、停补调课记录、出勤码、窗口位置、显示设置。 |
| `settings.json` | 应用全局 | 当前加载的教师配置文件路径、界面外观参数。 |

三个文件均以 UTF-8 编码保存，使用 JSON 标准格式（`ensure_ascii=False`，缩进 2 空格）。

---

## 2. school_config.json

### 2.1 顶层结构

```json
{
  "periods": { ... },
  "course_types": { ... },
  "semesters": [ ... ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `periods` | object | 时限定义，键为时限编号字符串 `"1"`～`"6"` |
| `course_types` | object | 课程类型定义，键为类型 ID |
| `semesters` | array | 学期日程列表，每个元素为一个学期 |

以 `_` 开头的字段（如 `_comment`、`_skipped_dates`）为注释字段，加载时被忽略。

---

### 2.2 periods 字段

定义一天中各时限的起止时间。

```json
"periods": {
  "1": { "start": "08:50", "end": "10:30" },
  "2": { "start": "10:40", "end": "12:20" },
  "3": { "start": "13:10", "end": "14:50" },
  "4": { "start": "15:00", "end": "16:40" },
  "5": { "start": "16:50", "end": "18:30" },
  "6": { "start": "18:40", "end": "20:20" }
}
```

- 键为时限编号字符串，固定为 `"1"` 至 `"6"`，共 6 个时限。
- `start` 和 `end` 均为 `HH:MM` 格式的 24 小时制时间字符串。
- 以上为 2026 年度的实际值。

---

### 2.3 course_types 字段

定义各课程类型与学期、回次的对应关系。

```json
"course_types": {
  "<type_id>": {
    "name": "string",
    "semester_id": "string",
    "session_keys": ["01", "02", ...],
    "slots_per_week": 1
  }
}
```

| 子字段 | 类型 | 说明 |
|--------|------|------|
| `name` | string | 课程类型的显示名称 |
| `semester_id` | string | 引用 `semesters[].semester_id` |
| `session_keys` | array of string | 本类型使用的回次键列表，零填充两位数字 |
| `slots_per_week` | integer | 每周授课次数，`1` 或 `2` |

2026 年度的 6 种课程类型实际值如下：

```json
"course_types": {
  "spring": {
    "name": "春セメスター",
    "semester_id": "spring_2026",
    "session_keys": ["01","02","03","04","05","06","07","08","09","10","11","12","13","14"],
    "slots_per_week": 1
  },
  "autumn": {
    "name": "秋セメスター",
    "semester_id": "autumn_2026",
    "session_keys": ["01","02","03","04","05","06","07","08","09","10","11","12","13","14"],
    "slots_per_week": 1
  },
  "Q1": {
    "name": "第1クォーター（春前半）",
    "semester_id": "spring_2026",
    "session_keys": ["01","02","03","04","05","06","07"],
    "slots_per_week": 2
  },
  "Q2": {
    "name": "第2クォーター（春後半）",
    "semester_id": "spring_2026",
    "session_keys": ["08","09","10","11","12","13","14"],
    "slots_per_week": 2
  },
  "Q3": {
    "name": "第3クォーター（秋前半）",
    "semester_id": "autumn_2026",
    "session_keys": ["01","02","03","04","05","06","07"],
    "slots_per_week": 2
  },
  "Q4": {
    "name": "第4クォーター（秋後半）",
    "semester_id": "autumn_2026",
    "session_keys": ["08","09","10","11","12","13","14"],
    "slots_per_week": 2
  }
}
```

各类型的回次数量与每周课时的关系：

| 类型 | 所属学期 | 回次范围 | 回次数 | 每周课时 |
|------|----------|----------|--------|----------|
| `spring` | 春学期 | 01～14 | 14 | 1 |
| `autumn` | 秋学期 | 01～14 | 14 | 1 |
| `Q1` | 春学期前半 | 01～07 | 7 | 2 |
| `Q2` | 春学期后半 | 08～14 | 7 | 2 |
| `Q3` | 秋学期前半 | 01～07 | 7 | 2 |
| `Q4` | 秋学期后半 | 08～14 | 7 | 2 |

### 2.4 semesters 字段

`semesters` 为数组，每个元素描述一个学期的授课日程。

```json
"semesters": [
  {
    "semester_id": "string",
    "semester_name": "string",
    "semester_start": "YYYY-MM-DD",
    "semester_end": "YYYY-MM-DD",
    "weekday_dates": {
      "Monday":    { "01": "YYYY-MM-DD", "02": "YYYY-MM-DD", ..., "14": "YYYY-MM-DD" },
      "Tuesday":   { "01": "YYYY-MM-DD", ... },
      "Wednesday": { "01": "YYYY-MM-DD", ... },
      "Thursday":  { "01": "YYYY-MM-DD", ... },
      "Friday":    { "01": "YYYY-MM-DD", ... }
    }
  }
]
```

**weekday_dates 的语义：**

- 外层键为英文星期名（`"Monday"` ～ `"Friday"`）。
- 内层键为回次键字符串（`"01"` ～ `"14"`），零填充两位。
- 值为该曜日第 N 回对应的实际授课日期，`YYYY-MM-DD` 格式。
- 若该曜日某回次因节假日等原因停课，该键直接省略（不填 `null`）。
- 同一学期内，不同曜日的授课日期彼此独立，同一回次键对应的日期不一定相同。

### 2.5 字段必要性表

**periods 相关：**

| 字段路径 | 类型 | 必须/可选 | 说明 |
|----------|------|-----------|------|
| `periods` | object | 必须 | 时限定义对象 |
| `periods["1"]`～`periods["6"]` | object | 必须 | 共 6 个时限，键为字符串 `"1"`～`"6"` |
| `periods[n].start` | string | 必须 | 时限开始时间，`HH:MM` 格式 |
| `periods[n].end` | string | 必须 | 时限结束时间，`HH:MM` 格式 |

**course_types 相关：**

| 字段路径 | 类型 | 必须/可选 | 说明 |
|----------|------|-----------|------|
| `course_types` | object | 必须 | 课程类型对象 |
| `course_types[type_id].name` | string | 必须 | 类型显示名称 |
| `course_types[type_id].semester_id` | string | 必须 | 对应 `semesters[].semester_id` |
| `course_types[type_id].session_keys` | array of string | 必须 | 该类型有效的回次键列表 |
| `course_types[type_id].slots_per_week` | integer | 必须 | 每周课时数，`1` 或 `2` |

**semesters 相关：**

| 字段路径 | 类型 | 必须/可选 | 说明 |
|----------|------|-----------|------|
| `semesters` | array | 必须 | 学期列表，至少 1 个元素 |
| `semesters[].semester_id` | string | 必须 | 学期唯一标识符 |
| `semesters[].semester_name` | string | 必须 | 学期显示名称 |
| `semesters[].semester_start` | string | 必须 | 学期开始日期，`YYYY-MM-DD` 格式 |
| `semesters[].semester_end` | string | 必须 | 学期结束日期，`YYYY-MM-DD` 格式 |
| `semesters[].weekday_dates` | object | 必须 | 各曜日的回次→日期映射 |
| `semesters[].weekday_dates["Monday"]` 等 | object | 可选 | 若该曜日无课可省略整个键 |
| `semesters[].weekday_dates[weekday]["01"]` 等 | string | 可选 | 节假日停课的回次键直接省略 |

## 3. teacher_config.json

### 3.1 顶层结构

```json
{
  "teacher_name": "string",
  "academic_year": "string",
  "courses": [ ... ],
  "overrides": [ ... ],
  "attendance_codes": { ... },
  "window_position": { "x": 100, "y": 100 },
  "settings": {
    "pre_class_minutes": 10,
    "post_class_minutes": 30
  }
}
```

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `teacher_name` | string | `""` | 教师姓名（仅作标注，不影响逻辑） |
| `academic_year` | string | `""` | 学年，如 `"2026"` |
| `courses` | array | `[]` | 课程列表 |
| `overrides` | array | `[]` | 停课/补课/调课记录列表 |
| `attendance_codes` | object | `{}` | 各回次出勤码字典 |
| `window_position` | object | `{"x":100,"y":100}` | 出勤码窗口上次显示位置 |
| `settings` | object | 见下 | 上课提示时间参数 |

---

### 3.2 courses 数组

每个课程对象的结构：

```json
{
  "id": "string",
  "name": "string",
  "course_code": "string",
  "course_type": "string",
  "slots": [
    { "weekday": "Monday", "period": 3 }
  ]
}
```

| 字段 | 类型 | 必须/可选 | 说明 |
|------|------|-----------|------|
| `id` | string | 必须 | 课程唯一标识符，用于关联 `overrides` 和 `attendance_codes` |
| `name` | string | 必须 | 课程显示名称 |
| `course_code` | string | 可选 | 教务系统课程代码，省略时默认 `""` |
| `course_type` | string | 必须 | 课程类型，见下表 |
| `slots` | array | 必须 | 授课时间槽列表 |
| `slots[].weekday` | string | 必须 | 英文星期名，`"Monday"` ～ `"Friday"` |
| `slots[].period` | integer | 必须 | 时限编号，`1`～`6` |
| `_out_of_scope` | boolean | 可选 | 设为 `true` 时该课程在加载时被忽略 |

**course_type 取值：**

| 值 | 说明 | slots 数量 |
|----|------|------------|
| `"spring"` | 春学期课程 | 1 |
| `"autumn"` | 秋学期课程 | 1 |
| `"Q1"` | 第1クォーター（春前半） | 2 |
| `"Q2"` | 第2クォーター（春后半） | 2 |
| `"Q3"` | 第3クォーター（秋前半） | 2 |
| `"Q4"` | 第4クォーター（秋后半） | 2 |
| `"intensive"` | 集中講義 | 忽略（不参与日程计算） |

Q1/Q2/Q3/Q4 类型均为每周 2 课时（`CourseType.slots_per_week=2`），因此 `slots` 必须含 2 个元素（两个不同曜日各 1 个时间槽）。若 Q 类型课程只配置 1 个 slot，调度引擎会生成不连续的 session_key（01, 03, 05…），属于配置错误。spring / autumn 每周 1 课时，`slots` 含 1 个元素。`"intensive"` 类型的课程不参与自动日程推算，加载后不生成回次列表。

**示例：**

```json
{
  "id": "RD010001E3",
  "name": "日本語読解IA",
  "course_code": "RD010001E3",
  "course_type": "Q1",
  "slots": [
    { "weekday": "Monday", "period": 3 },
    { "weekday": "Thursday", "period": 3 }
  ]
}
```

### 3.3 overrides 数组

`overrides` 记录对正常日程的三类变更。每条记录必须包含 `type` 和 `course_id` 字段，其余字段依类型而定。

#### 停课（skip）

取消某日的正常授课，该回次不计入日程。

```json
{
  "type": "skip",
  "course_id": "RD010001E3",
  "date": "2026-05-11"
}
```

| 字段 | 类型 | 必须/可选 | 说明 |
|------|------|-----------|------|
| `type` | string | 必须 | 固定为 `"skip"` |
| `course_id` | string | 必须 | 对应 `courses[].id` |
| `date` | string | 必须 | 停课日期，`YYYY-MM-DD` 格式 |

#### 补课（makeup）

在原日程之外增加一次授课。

```json
{
  "type": "makeup",
  "course_id": "RD010001E3",
  "date": "2026-06-13",
  "period": 4
}
```

| 字段 | 类型 | 必须/可选 | 说明 |
|------|------|-----------|------|
| `type` | string | 必须 | 固定为 `"makeup"` |
| `course_id` | string | 必须 | 对应 `courses[].id` |
| `date` | string | 必须 | 补课日期，`YYYY-MM-DD` 格式 |
| `period` | integer | 可选 | 补课时限，`1`～`6`；省略则沿用原课程时限 |

#### 调课（reschedule）

将某次正常授课移至另一天（或另一时限）。

```json
{
  "type": "reschedule",
  "course_id": "RD010001E3",
  "original_date": "2026-05-18",
  "original_period": 3,
  "new_date": "2026-05-19",
  "new_period": 2
}
```

若调整为非标准时间，使用 `new_start_time` 代替 `new_period`：

```json
{
  "type": "reschedule",
  "course_id": "RD010001E3",
  "original_date": "2026-06-08",
  "original_period": 3,
  "new_date": "2026-06-09",
  "new_start_time": "09:00"
}
```

| 字段 | 类型 | 必须/可选 | 说明 |
|------|------|-----------|------|
| `type` | string | 必须 | 固定为 `"reschedule"` |
| `course_id` | string | 必须 | 对应 `courses[].id` |
| `original_date` | string | 必须 | 原授课日期，`YYYY-MM-DD` 格式 |
| `original_period` | integer | 必须 | 原授课时限，`1`～`6` |
| `new_date` | string | 必须 | 调整后的授课日期，`YYYY-MM-DD` 格式 |
| `new_period` | integer | 二选一 | 调整后的时限，`1`～`6`；与 `new_start_time` 二选一；两者均缺省时沿用被调课程的原时限 |
| `new_start_time` | string | 二选一 | 自定义开始时间，`HH:MM` 格式（对应内部 `new_period=0`）；与 `new_period` 二选一；提供本字段时 `new_period` 被忽略 |

序列化时，值为 `None` 或空字符串的字段会自动省略，不写入 JSON 文件。

---

### 3.4 attendance_codes 字典

记录各课程各回次的出勤码字符串。

```json
"attendance_codes": {
  "{course_id}_{session_key}": "code_string"
}
```

- 键格式：`{course_id}_{session_key}`，其中 `session_key` 为两位零填充数字字符串。
- 值：出勤码字符串，内容由教师自定义（通常为 4～6 位字母数字组合）。
- 若某回次尚未设置出勤码，该键不存在于字典中（不填 `null`）。

**示例：**

```json
"attendance_codes": {
  "RD010001E3_01": "A1B2",
  "RD010001E3_02": "C3D4",
  "RD010001E3_03": "E5F6"
}
```

上例表示课程 `RD010001E3` 的第 1 回出勤码为 `A1B2`，第 2 回为 `C3D4`，第 3 回为 `E5F6`。

---

### 3.5 window_position 和 settings 字段

**window_position：** 记录出勤码展示窗口的上次屏幕位置，供下次启动时恢复。

```json
"window_position": { "x": 100, "y": 100 }
```

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `x` | integer | `100` | 窗口左上角 X 坐标（像素） |
| `y` | integer | `100` | 窗口左上角 Y 坐标（像素） |

**settings：** 控制出勤码窗口弹出和关闭的时间逻辑。

```json
"settings": {
  "pre_class_minutes": 10,
  "post_class_minutes": 30
}
```

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `pre_class_minutes` | integer | `10` | 上课开始前若干分钟弹出出勤码窗口 |
| `post_class_minutes` | integer | `30` | 上课开始后若干分钟内保持窗口可见 |

| 字段路径 | 类型 | 必须/可选 | 默认值 | 说明 |
|----------|------|-----------|--------|------|
| `teacher_name` | string | 可选 | `""` | 教师姓名标注 |
| `academic_year` | string | 可选 | `""` | 学年字符串，如 `"2026"` |
| `courses` | array | 可选 | `[]` | 课程列表 |
| `courses[].id` | string | 必须 | — | 课程唯一 ID |
| `courses[].name` | string | 必须 | — | 课程显示名称 |
| `courses[].course_code` | string | 可选 | `""` | 教务课程代码 |
| `courses[].course_type` | string | 必须 | — | 课程类型 |
| `courses[].slots` | array | 必须 | — | 授课时间槽列表 |
| `courses[].slots[].weekday` | string | 必须 | — | 英文星期名 |
| `courses[].slots[].period` | integer | 必须 | — | 时限编号 `1`～`6` |
| `courses[]._out_of_scope` | boolean | 可选 | `false` | `true` 则加载时跳过 |
| `overrides` | array | 可选 | `[]` | 停补调课记录 |
| `overrides[].type` | string | 必须 | — | `"skip"` / `"makeup"` / `"reschedule"` |
| `overrides[].course_id` | string | 必须 | — | 对应课程 ID |
| `overrides[].date` | string | skip/makeup 必须 | — | 日期 `YYYY-MM-DD` |
| `overrides[].period` | integer | 可选 | 原课时限 | makeup 时限 |
| `overrides[].original_date` | string | reschedule 必须 | — | 原授课日期 |
| `overrides[].original_period` | integer | reschedule 必须 | — | 原授课时限 |
| `overrides[].new_date` | string | reschedule 必须 | — | 调整后日期 |
| `overrides[].new_period` | integer | 二选一 | — | 调整后时限 |
| `overrides[].new_start_time` | string | 二选一 | — | 自定义开始时间 `HH:MM` |
| `attendance_codes` | object | 可选 | `{}` | 出勤码字典 |
| `window_position` | object | 可选 | `{"x":100,"y":100}` | 窗口位置 |
| `window_position.x` | integer | 可选 | `100` | X 坐标 |
| `window_position.y` | integer | 可选 | `100` | Y 坐标 |
| `settings` | object | 可选 | 见默认值 | 时间参数 |
| `settings.pre_class_minutes` | integer | 可选 | `10` | 提前弹出分钟数 |
| `settings.post_class_minutes` | integer | 可选 | `30` | 课后保持分钟数 |

## 4. settings.json

应用全局设置，控制当前加载哪份教师配置以及界面外观。

```json
{
  "active_config": "",
  "appearance": {
    "code_font_family": "Arial",
    "code_font_size": 72,
    "code_color": "#00ff7f",
    "code_bg_color": "#ffffff",
    "border_color": "#90CAF9",
    "course_font_family": "",
    "course_font_size": 11,
    "window_scale": 100
  }
}
```

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `active_config` | string | `""` | 当前教师配置文件的绝对路径；空字符串表示使用程序内置的默认路径 |
| `appearance` | object | 见下 | 界面外观参数 |
| `appearance.code_font_family` | string | `"Arial"` | 出勤码字体名称 |
| `appearance.code_font_size` | integer | `72` | 出勤码字体大小（点） |
| `appearance.code_color` | string | `"#00ff7f"` | 出勤码文字颜色，十六进制 CSS 颜色 |
| `appearance.code_bg_color` | string | `"#ffffff"` | 出勤码窗口背景色，十六进制 CSS 颜色 |
| `appearance.border_color` | string | `"#90CAF9"` | 出勤码窗口边框颜色，十六进制 CSS 颜色 |
| `appearance.course_font_family` | string | `""` | 课程名称字体名称；空字符串表示使用系统默认字体 |
| `appearance.course_font_size` | integer | `11` | 课程名称字体大小（点） |
| `appearance.window_scale` | integer | `100` | 出勤码窗口缩放比例（百分比，有效范围 30～300） |

颜色值格式：`#RRGGBB`，大小写均可，必须包含 `#` 前缀。

`window_scale` 为 `100` 表示 100%（原始尺寸），`150` 表示放大至 150%。

若 `settings.json` 文件不存在，程序会使用上表中所有字段的默认值启动，不报错。

## 5. 文件位置

| 运行模式 | 文件位置 |
|----------|----------|
| 开发模式 | 项目根目录下的 `config/` 子目录 |
| 打包后（Windows） | EXE 同级目录的 `config/` 子目录 |
| 打包后（macOS） | `.app` 包所在文件夹的 `config/` 子目录（即 `.app` 外部的同级 `config/`） |

三个文件的文件名固定：

- `config/school_config.json`
- `config/settings.json`
- `config/<教师名>_teacher_config.json`（教师配置文件名可自定义，由 `settings.json` 的 `active_config` 字段指定绝对路径）

## 6. 初始化行为（首次运行）

若 `config/` 目录或配置文件不存在，程序会自动将打包在可执行文件内部的模板文件复制到 `config/` 目录下，并以默认内容创建缺失的文件。

模板文件（`teacher_config.json` 的默认内容）：

```json
{
  "teacher_name": "",
  "academic_year": "2026",
  "courses": [],
  "overrides": [],
  "attendance_codes": {},
  "window_position": {"x": 100, "y": 100},
  "settings": {
    "pre_class_minutes": 10,
    "post_class_minutes": 30
  }
}
```

首次运行后，用户需手动编辑 `teacher_config.json`（或复制一份已有教师配置），填入课程信息和出勤码。
