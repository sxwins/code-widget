> 源码参考（仅供核实）：

## 1. 概述

调度引擎分为两个阶段：

1. **日期解析阶段**（`resolve_course_schedule`）：将教师配置中的课程定义（课程类型 + 上课时间槽）展开为一学期内所有具体的上课记录（`ScheduledClass`列表）。每条 `ScheduledClass` 代表一次实际上课的日期、时限和回次编号。

2. **Override 应用阶段**（`apply_overrides`）：在上一步生成的列表基础上，依次应用教师配置的调整记录（停课、补课、调课），最终输出修正后的 `ScheduledClass` 列表，并重新编号。

两阶段完成后，调度结果用于：
- 计算每节课的展示窗口时间范围（`compute_window`）
- 判断当前时刻是否处于某节课的活动窗口（`get_active_class`）

## 2. 核心数据结构

### 2.1 输入：SchoolConfig（全校配置）

```
SchoolConfig:
  periods: dict[str, Period]
      key: "1"~"6"（字符串）
      Period.start: str   — 开始时间，格式 "HH:MM"
      Period.end:   str   — 结束时间，格式 "HH:MM"

  course_types: dict[str, CourseType]
      key: "spring" | "autumn" | "Q1" | "Q2" | "Q3" | "Q4"
      CourseType.semester_id:   str       — 所属学期ID
      CourseType.session_keys:  list[str] — 回次键列表（见下文）
      CourseType.slots_per_week: int      — 每周插槽数（1 或 2）

  semesters: list[SemesterDates]
      SemesterDates.semester_id:    str
      SemesterDates.semester_name:  str
      SemesterDates.semester_start: str   — "YYYY-MM-DD"
      SemesterDates.semester_end:   str   — "YYYY-MM-DD"
      SemesterDates.weekday_dates:  dict[str, dict[str, str]]
          外层key: 星期英文名（"Monday"/"Tuesday"/"Wednesday"/"Thursday"/"Friday"）
          内层key: 回次键（"01"~"14"）
          内层value: 具体日期字符串 "YYYY-MM-DD"
```

**session_keys 的含义**：

| course_type | session_keys | slots_per_week | 说明 |
|-------------|--------------|----------------|------|
| spring | "01"~"14" | 1 | 春セメスター，14回 |
| autumn | "01"~"14" | 1 | 秋セメスター，14回 |
| Q1 | "01"~"07" | 2 | 第1クォーター（春前半），7周×2插槽=14回 |
| Q2 | "08"~"14" | 2 | 第2クォーター（春後半），7周×2插槽=14回 |
| Q3 | "01"~"07" | 2 | 第3クォーター（秋前半），7周×2插槽=14回 |
| Q4 | "08"~"14" | 2 | 第4クォーター（秋後半），7周×2插槽=14回 |

注意：Q2/Q4 的 session_keys 起始为 "08"，这是因为它们与 Q1/Q3 共用同一个学期的 weekday_dates，通过不同的键范围索引不同半段的日期。

### 2.2 输入：Course（课程定义）

```
Course:
  id:          str   — 课程ID（唯一标识）
  name:        str   — 课程名称
  course_type: str   — "spring" | "autumn" | "Q1" | "Q2" | "Q3" | "Q4" | "intensive"
  slots:       list[Slot]
      Slot.weekday: str — 星期英文名（"Monday"/"Tuesday"/...）
      Slot.period:  int — 时限（1～6）
  course_code: str   — 课程代码（可为空）
```

单插槽课程（spring/autumn）有 1 个 Slot；Q 类课程有 2 个 Slot（对应每周两次上课）。

### 2.3 输出：ScheduledClass（排课结果，核心数据结构）

```
ScheduledClass:
  course_id:    str  — 课程ID（与Course.id一致）
  course_name:  str  — 课程名称
  date:         date — 上课日期（Python date对象，YYYY-MM-DD）
  weekday:      str  — 星期英文名（"Monday"/"Tuesday"/"Wednesday"/"Thursday"/"Friday"）
  period:       int  — 时限（1～6；调课到自定义时间时可能为0）
  session_key:  str  — 回次编号（"01"~"14"，Override后重新编号）
  slot_index:   int  — 插槽索引（0 或 1；Q类课程的第一个slot为0，第二个slot为1）
  custom_start: str  — 自定义开始时间（格式 "HH:MM"；仅调课到非标准时限时使用；默认为空字符串""）
```

### 2.4 输入：Override（调整记录）

```
Override:
  type:            str       — "skip" | "makeup" | "reschedule"
  course_id:       str       — 目标课程ID

  # skip / makeup 共用：
  date:            str       — 目标日期（"YYYY-MM-DD"；skip 为停课日，makeup 为补课日）

  # makeup 专用：
  period:          int|None  — 补课时限（可选；None 时沿用该课程现有记录的时限）
                               注意：skip 不使用此字段（_apply_skip 仅读取 date 与 course_id）

  # reschedule 使用：
  original_date:   str       — 原上课日期（"YYYY-MM-DD"）
  original_period: int|None  — 原时限（可选；None时匹配该日期下所有时限）
  new_date:        str       — 调课后新日期（"YYYY-MM-DD"）
  new_period:      int|None  — 调课后新时限（可选）
  new_start_time:  str       — 调课后自定义开始时间（"HH:MM"）；
                               与 new_period 二选一，如同时提供则本字段优先
                               （new_period 被忽略，period 固定设为 0）
```

## 3. 授课日期解析（resolve_course_schedule）

**函数签名**：`resolve_course_schedule(course, school_config) -> list[ScheduledClass]`

### 3.1 特殊情况：intensive 类型

若 `course.course_type == "intensive"`，直接返回空列表。集中授课课程不纳入自动排课。

### 3.2 前置步骤：查找 CourseType 和 SemesterDates

```
1. ct = school_config.course_types.get(course.course_type)
   若 ct 为 None（未知课程类型）→ 返回空列表

2. semester = school_config.get_semester(ct.semester_id)
   若 semester 为 None（学期ID不存在）→ 返回空列表

3. 后续操作使用：
   ct.session_keys    — 回次键列表
   ct.slots_per_week  — 每周插槽数（决定走哪条分支）
   semester.weekday_dates — 日期查找表
```

### 3.3 单插槽课程（spring / autumn，slots_per_week == 1）

适用于 course_type 为 "spring" 或 "autumn" 的课程，每周只有一次上课。

**算法**（伪代码）：

```
result = []
for slot_idx, slot in enumerate(course.slots):          # 通常只有 1 个 slot
    wd_dates = semester.weekday_dates.get(slot.weekday, {})
    for session_key in ct.session_keys:                 # "01"~"14"
        date_str = wd_dates.get(session_key)
        if date_str is None:
            continue                                    # 该回次无对应日期，跳过
        result.append(ScheduledClass(
            course_id    = course.id,
            course_name  = course.name,
            date         = date.fromisoformat(date_str),
            weekday      = slot.weekday,
            period       = slot.period,
            session_key  = session_key,                 # 直接使用 "01"~"14"
            slot_index   = slot_idx,                    # 通常为 0
            custom_start = "",
        ))
return result
```

**结果**：正常情况下生成 14 个 `ScheduledClass`，session_key 直接为 "01"~"14"。

**日期跳过机制**：若某个 session_key 在 weekday_dates 中不存在对应日期（例如因节假日该周无该曜日授课），则跳过该回次，不生成对应记录。最终数量可能少于 14。

### 3.4 双插槽课程（Q1 / Q2 / Q3 / Q4，slots_per_week == 2）

Q 类课程每周上课两次（例如周三+周五），每次对应一个 slot。session_key 需在两个 slot 间连续递增，不能各自从"01"开始。

**算法**（伪代码）：

```
result = []
for week_idx, week_key in enumerate(ct.session_keys):  # 7个回次键
    for slot_idx, slot in enumerate(course.slots):      # 2个slot
        wd_dates = semester.weekday_dates.get(slot.weekday, {})
        date_str = wd_dates.get(week_key)
        if date_str is None:
            continue                                    # 该周该曜日无课，跳过
        actual_num = week_idx * ct.slots_per_week + slot_idx + 1
        # 连续编号：第0周slot0→1, slot1→2；第1周slot0→3, slot1→4；...
        result.append(ScheduledClass(
            course_id    = course.id,
            course_name  = course.name,
            date         = date.fromisoformat(date_str),
            weekday      = slot.weekday,
            period       = slot.period,
            session_key  = f"{actual_num:02d}",         # "01"~"14"
            slot_index   = slot_idx,                    # 0 或 1
            custom_start = "",
        ))
return result
```

**actual_num 计算公式**：`actual_num = week_idx * slots_per_week + slot_idx + 1`

- 两个参数从 0 开始（week_idx、slot_idx），+1 使结果从 1 开始。
- `slots_per_week` 固定为 2，因此每周两个编号连续递增。

**结果**：正常情况下生成 14 个 `ScheduledClass`（7周 × 2插槽）。

### 3.5 Q 类课程编号举例

以 Q1 课程（周三2限 + 周五3限）为例，使用2026年春季学期真实日期：

| week_idx | week_key | slot_idx | slot.weekday | actual_num | session_key | 实际日期 |
|----------|----------|----------|--------------|-----------|-------------|---------|
| 0 | "01" | 0 | Wednesday | 1 | "01" | 2026-04-15 |
| 0 | "01" | 1 | Friday | 2 | "02" | 2026-04-17 |
| 1 | "02" | 0 | Wednesday | 3 | "03" | 2026-04-22 |
| 1 | "02" | 1 | Friday | 4 | "04" | 2026-04-24 |
| 2 | "03" | 0 | Wednesday | 5 | "05" | 2026-04-29 |
| 2 | "03" | 1 | Friday | 6 | "06" | 2026-05-08 |
| 3 | "04" | 0 | Wednesday | 7 | "07" | 2026-05-13 |
| 3 | "04" | 1 | Friday | 8 | "08" | 2026-05-15 |
| 4 | "05" | 0 | Wednesday | 9 | "09" | 2026-05-20 |
| 4 | "05" | 1 | Friday | 10 | "10" | 2026-05-22 |
| 5 | "06" | 0 | Wednesday | 11 | "11" | 2026-05-27 |
| 5 | "06" | 1 | Friday | 12 | "12" | 2026-05-29 |
| 6 | "07" | 0 | Wednesday | 13 | "13" | 2026-06-03 |
| 6 | "07" | 1 | Friday | 14 | "14" | 2026-06-05 |

注意第3行 slot_idx=1（Friday）的日期为 2026-05-08 而非 2026-05-01，因为 school_config 中已将 2026-05-01 标注为休日，该日期从 weekday_dates 中去除（week_key "03" 对应的 Friday 直接跳到 05-08）。

### 3.6 Q2 课程的特殊说明

Q2 的 session_keys 为 "08"~"14"（而非 "01"~"07"）。这与 Q1 共用同一个 `spring_2026` 学期的 `weekday_dates`，但索引后半段的日期。week_idx 同样从 0 开始枚举：

| week_idx | week_key | slot_idx | actual_num | session_key |
|----------|----------|----------|-----------|-------------|
| 0 | "08" | 0 | 1 | "01" |
| 0 | "08" | 1 | 2 | "02" |
| 1 | "09" | 0 | 3 | "03" |
| ... | ... | ... | ... | ... |
| 6 | "14" | 1 | 14 | "14" |

Q2 课程生成的 session_key 最终也是 "01"~"14"，与 Q1 相同。

## 4. Override 应用（apply_overrides）

**函数签名**：`apply_overrides(scheduled, overrides) -> list[ScheduledClass]`

### 4.1 整体流程

```
1. result = 复制 scheduled 列表（浅拷贝，避免修改原始列表）

2. 按 overrides 列表顺序，逐条应用：
   for ov in overrides:
       if ov.type == "skip":
           result = _apply_skip(result, ov)
       elif ov.type == "makeup":
           result = _apply_makeup(result, ov)
       elif ov.type == "reschedule":
           result = _apply_reschedule(result, ov)

3. result.sort(key=lambda sc: (sc.date, sc.period))   # 按日期+时限排序

4. result = _reassign_session_keys(result)             # 重新编号

5. return result
```

重要：每条 override 处理完整个列表再处理下一条，不是批量并行处理。

### 4.2 停课（skip）

**用途**：取消某课程在特定日期的全部上课。

**输入参数**：
- `ov.type = "skip"`
- `ov.course_id`：目标课程ID
- `ov.date`：停课日期（"YYYY-MM-DD"）

**操作**：从列表中移除所有同时满足以下两个条件的条目：
- `sc.course_id == ov.course_id`
- `sc.date == date.fromisoformat(ov.date)`

若该日期某Q类课程有两个 slot（slot_index=0 和 slot_index=1），两者都会被移除。

**伪代码**：
```
skip_date = date.fromisoformat(ov.date)
result = [
    sc for sc in scheduled
    if not (sc.course_id == ov.course_id and sc.date == skip_date)
]
```

**效果示例**：原有14条记录，停课1次后剩13条。Override后编号重排，session_key 变为 "01"~"13"。

### 4.3 补课（makeup）

**用途**：在常规排课之外追加一次补课。

**输入参数**：
- `ov.type = "makeup"`
- `ov.course_id`：目标课程ID
- `ov.date`：补课日期（"YYYY-MM-DD"）
- `ov.period`：（可选）补课时限；若为 None，则沿用该课程第一条记录的时限

**操作**：

```
1. 在当前 scheduled 列表中，找第一个 course_id 匹配的 ScheduledClass 作为参考（ref）：
   ref = 找到第一个 sc.course_id == ov.course_id 的条目
   若找不到 ref → 不做任何修改，直接返回原列表

2. 构造新的 ScheduledClass：
   new_date = date.fromisoformat(ov.date)
   new_sc = ScheduledClass(
       course_id    = ref.course_id,
       course_name  = ref.course_name,
       date         = new_date,
       weekday      = new_date.strftime("%A"),   # 由日期推算星期名
       period       = ov.period if ov.period is not None else ref.period,
       session_key  = "",       # 留空，后续由 _reassign_session_keys 填写
       slot_index   = 0,        # 补课始终为 slot 0
       custom_start = "",
   )

3. result = scheduled + [new_sc]   # 追加到列表末尾
```

注意：`weekday` 字段由 `new_date` 直接推算（Python 的 `strftime("%A")` 返回英文星期全名），不依赖配置文件。

**效果示例**：原有14条记录，补课1次后共15条。Override后编号重排，补课记录按日期排序后分配相应的 session_key（若补课日期最晚，则为 "15"）。

### 4.4 调课（reschedule）

**用途**：将某节课从原定日期/时限移至新日期/时限（可选择指定非标准开始时间）。

**输入参数**：
- `ov.type = "reschedule"`
- `ov.course_id`：目标课程ID
- `ov.original_date`：原上课日期（"YYYY-MM-DD"）
- `ov.original_period`：（可选）原时限；若为 None，则移除该日期下该课程的所有时限
- `ov.new_date`：调课后新日期（"YYYY-MM-DD"）
- `ov.new_period`：（可选）调课后新时限
- `ov.new_start_time`：（可选）调课后自定义开始时间（"HH:MM"）；与 `new_period` 互斥，优先级更高

**操作**：

```
步骤1：移除原始记录
orig_date = date.fromisoformat(ov.original_date)
result = [
    sc for sc in scheduled
    if not (
        sc.course_id == ov.course_id
        and sc.date == orig_date
        and (ov.original_period is None or sc.period == ov.original_period)
    )
]

步骤2：在移除后的列表中找参考记录
ref = 找到第一个 sc.course_id == ov.course_id 的条目（在已移除原记录的 result 中查找）
若 ref 为 None 或 ov.new_date 为空 → 不追加新记录，直接返回 result

步骤3：构造新记录
new_date = date.fromisoformat(ov.new_date)
if ov.new_start_time 非空:
    new_period   = 0         # 自定义时间时 period 设为 0
    custom_start = ov.new_start_time
else:
    new_period   = ov.new_period if ov.new_period is not None else ref.period
    custom_start = ""

new_sc = ScheduledClass(
    course_id    = ref.course_id,
    course_name  = ref.course_name,
    date         = new_date,
    weekday      = new_date.strftime("%A"),
    period       = new_period,
    session_key  = "",       # 留空，后续重新编号
    slot_index   = 0,        # 调课记录始终为 slot 0
    custom_start = custom_start,
)
result.append(new_sc)
```

**period = 0 的含义**：当指定了 `new_start_time` 时，`period` 设为 0 表示该节课不对应标准时限，开始时间由 `custom_start` 字段决定。

**效果示例**：原有14条记录，调课后仍为14条（1条被移除，1条被新增）。

### 4.5 Override 后处理

所有 override 处理完成后执行：

```
1. result.sort(key=lambda sc: (sc.date, sc.period))
   — 先按日期升序，同日期内按时限升序排序。
   — period=0 的记录（自定义开始时间）会排在该日期所有标准时限之前。
   — 已知局限：若同一日期存在多个 period=0 的记录（即同天多次调课且均
     指定了自定义时间），这些记录的排序键完全相同 (date, 0)，实际顺序
     由 Python 稳定排序保持前一步的相对顺序，并非按 custom_start 时间
     先后排列（详见 TECHNICAL_DEBT.md TD-02）。

2. result = _reassign_session_keys(result)
   — 重新为所有课程分配 session_key（见第5节）。
```

---

## 5. session_key 重新编号（_reassign_session_keys）

**调用时机**：`apply_overrides` 的最后一步，对整个结果列表统一重新编号。

### 5.1 多插槽课程检测

```
# 找出所有拥有 slot_index > 0 记录的 course_id
multi_slot_courses = {sc.course_id for sc in scheduled if sc.slot_index > 0}
```

若某课程有任何 `slot_index > 0` 的记录（即该课程至少有2个slot），则该课程被认定为多插槽课程。

### 5.2 分组规则

```
groups = {}
for sc in scheduled:
    if sc.course_id in multi_slot_courses:
        key = sc.course_id              # 多插槽课程：所有slot合并为一组
    else:
        key = (sc.course_id, sc.slot_index)  # 单插槽课程：按(课程ID, slot索引)分组
    groups[key].append(sc)
```

- **单插槽课程**（spring/autumn）：按 `(course_id, slot_index)` 分组。同一课程的所有回次在同一分组内连续编号。通常 slot_index 固定为 0，所以等同于按 course_id 分组。
- **多插槽课程**（Q类）：仅按 `course_id` 分组，两个 slot 的记录放在同一分组，使 session_key 在两个曜日间保持连续。

### 5.3 编号逻辑

```
for group in groups.values():
    group.sort(key=lambda sc: (sc.date, sc.period))   # 组内按日期+时限排序
    for i, sc in enumerate(group):
        sc.session_key = f"{i + 1:02d}"               # "01", "02", ...

# 最终再次对全列表排序（确保返回结果有序）
scheduled.sort(key=lambda sc: (sc.date, sc.period))
return scheduled
```

对每个分组，按日期+时限顺序重新赋值 `session_key`，从 "01" 开始递增。

**重要**：该函数直接修改传入列表中各 `ScheduledClass` 对象的 `session_key` 字段（原地修改），并返回排序后的列表。

**已知局限**：组内排序键同为 `(date, period)`。若同一组内同一日期存在多个 `period=0` 的记录（调课至相同日期且均指定自定义时间），这些记录的排序键完全相同，实际顺序取决于 Python 稳定排序保持的上一步相对顺序，而非 `custom_start` 时间先后。与 §4.5 中描述的局限源于同一根因（详见 TECHNICAL_DEBT.md TD-02）。

### 5.4 编号示例：停课后重编号

原始14条（spring，周四1限）→ 停课 2026-04-16（第1回）→ 剩13条 → 重编号：

| 移除前 session_key | 日期 | 移除后新 session_key |
|------------------|------|-------------------|
| "01" | 2026-04-16 | **（已移除）** |

## 6. 显示窗口计算（compute_window）

**函数签名**：`compute_window(sc, school_config, settings) -> (datetime, datetime)`

**用途**：计算一节课的出勤码展示窗口的开始和结束时刻。

**算法**：

```
步骤1：确定课程开始时间
if sc.custom_start 非空:
    # 解析自定义时间（调课到非标准时限时使用）
    h, m = 解析 sc.custom_start（格式 "HH:MM"）
else:
    # 查询标准时限表
    period_info = school_config.periods[str(sc.period)]   # key 为字符串
    h, m = 解析 period_info.start（格式 "HH:MM"）

步骤2：构造课程开始 datetime
class_start = datetime(sc.date.year, sc.date.month, sc.date.day, h, m)
（等价于 datetime.combine(sc.date, time(h, m))）

步骤3：计算展示窗口
window_start = class_start - timedelta(minutes=settings.pre_class_minutes)
window_end   = class_start + timedelta(minutes=settings.post_class_minutes)

return (window_start, window_end)
```

**默认 Settings 值**：
- `pre_class_minutes = 10`（课前10分钟开始展示）
- `post_class_minutes = 30`（课程开始后30分钟结束展示）

**示例**：spring 课程，2026-04-16（周四），1限（08:50开始），默认设置：
- `class_start = 2026-04-16 08:50`
- `window_start = 2026-04-16 08:40`（08:50 - 10分钟）
- `window_end   = 2026-04-16 09:20`（08:50 + 30分钟）

**窗口边界包含**：判断时为闭区间，即 `window_start <= now <= window_end` 时认为在窗口内（含两端点）。

## 7. 当前活动课程（get_active_class）

**函数签名**：`get_active_class(now, scheduled_classes, school_config, settings) -> ScheduledClass | None`

**用途**：给定当前时刻，从所有已排课记录中找出处于展示窗口内的那一节课。

**算法**：

```
步骤1：收集所有处于窗口内的课程
candidates = []
for sc in scheduled_classes:
    ws, we = compute_window(sc, school_config, settings)
    if ws <= now <= we:
        candidates.append((sc, ws))   # 保存 (ScheduledClass, window_start)

步骤2：若无匹配，返回 None
if not candidates:
    return None

步骤3：多个匹配时按规则排序，取第一个
candidates.sort(key=lambda x: (
    abs((now - x[1]).total_seconds()),  # 主排序：窗口开始时间与 now 的时间差绝对值（越小越优先）
    x[0].period                         # 次排序：时限越小越优先
))
return candidates[0][0]
```

**排序规则解析**：
- 主排序：`abs(now - window_start)`，即 `now` 距该课窗口开始时间越近（绝对值越小），优先级越高。
- 次排序：`period` 值越小越优先（用于打破主排序相同的平局）。

**典型情形**：大多数时刻只有零个或一个课程在窗口内，排序规则仅在同一时刻恰好有两节课的窗口重叠时才生效。

## 附录：数据流总览

```
SchoolConfig（school_config.json）
    ├── periods{}           → compute_window 使用
    ├── course_types{}      → resolve_course_schedule 使用
    └── semesters[]         → resolve_course_schedule 使用
            └── weekday_dates[weekday][session_key] → "YYYY-MM-DD"

TeacherConfig（*_teacher_config.json）
    ├── courses[]           → resolve_course_schedule 的输入
    ├── overrides[]         → apply_overrides 的输入
    └── settings{}          → compute_window / get_active_class 使用

resolve_course_schedule(course, school_config)
    └── list[ScheduledClass]（未经Override）

apply_overrides(scheduled, overrides)
    └── list[ScheduledClass]（经过skip/makeup/reschedule处理，session_key已重编）

compute_window(sc, school_config, settings)
    └── (window_start: datetime, window_end: datetime)

get_active_class(now, scheduled_classes, school_config, settings)
    └── ScheduledClass | None
```
